## 요청과 범위

사용자가 GitHub 해설 3편을 각각 최소 7,000자로 확장하고 GitHub merge와 PR/issue 정리를 승인했다. 이번 변경은 새 MDX 3개와 이 편집 기록만 추가한다. 사이트 디자인, CI, 워크플로, 원자료 수식, 광고 설정, 비밀정보는 변경하지 않는다.

세 글은 모두 `draft: true`를 유지한다. 저장소에 merge하는 것과 공개 기사로 발행하는 것은 구별한다. 기존 Navier–Stokes, WeatherNext 등 다른 초안의 공개 상태는 변경하지 않는다. Blogger 초안은 이번 변경에서 발행하거나 수정하지 않는다.
