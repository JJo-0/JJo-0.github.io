# AI가 설계한 단백질에 보이지 않는 출처 표시를 남길 수 있을까

편집일: 2026-10-01. 업데이트: 2026-10-05. Blogger 게시용 초안이며 외부 계정에는 발행하지 않았습니다.

Google DeepMind의 SynthID Bio는 AI 단백질 설계에 출처 신호를 더하는 연구입니다. 아미노산 서열에 표시하는 방법과 AlphaFold 3가 예측한 디지털 좌표에 표시하는 방법은 서로 다릅니다. 세 표적의 결합 단백질을 실제로 시험했다는 점은 강점이지만 모든 단백질의 기능이나 임상 효과를 보장한 것은 아닙니다.

검출률에도 분모가 있습니다. 서열의 100% 탐지는 0.1% 거짓 양성률에 맞춘 검출 필터를 통과한 설계 집합의 결과입니다. 구조의 99.8% 초과 탐지율은 예측 좌표 평가 결과이지 합성 단백질 분자에 물리적인 표지를 새겼다는 뜻이 아닙니다. 서열 재설계나 구조 처리로 표지가 지워질 수 있다는 한계도 남습니다.

출처 표시가 곧 안전 판정은 아닙니다. 전체 해설에서는 원논문 도판, 결합 친화도 계산 예제, 세부 실험의 예외와 공개 범위를 함께 설명합니다. 한국어 본문과 전체 영어판을 같은 글의 언어 버튼으로 오갈 수 있습니다.
