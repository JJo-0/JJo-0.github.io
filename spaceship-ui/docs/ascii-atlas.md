# Interactive Writing Atlas: automatic visible loading and clearer relationships

References: Andy Sloane, [Donut math](https://www.a1k0n.net/2011/07/20/donut-math.html), 2011, explains perspective and depth ordering for ASCII graphics. This graph uses its own category symbols and perspective fit rather than copying a rotating torus or treating a similarity graph as a solid surface.

The previous sparse dots made short edges disappear and used a depth glyph for all topics. The new rendering uses nine stable category glyphs and light/dark colors; all existing relationships are preserved. Same-category edges are continuous strokes, cross-category edges dashed; weight controls line width and depth controls node size. Depth order determines hit-box stacking. Hover or keyboard focus highlights only the incident edges and actual neighbors with a title/reason tooltip. Legend selection dims other categories (does not delete nodes), arrow buttons rotate and reset restores the starting view. Horizontal touch dragging remains available; vertical touch scrolling stays native.

Static preview remains server-rendered. The small loader schedules the full JSON and Canvas runtime after window load, a visible IntersectionObserver entry and an idle opportunity. A CSS animation is displayed only during loading, respects reduced motion, and stops on first paint or error. No GIF request, continuous rotation, or WebGL probing. Retry and native archive links remain available. The canvas draws only when dirty, now targeting display cadence up to approximately 60 Hz during a finite rotation transition, and stops offscreen. Frame-time exponential easing converges to the exact target, including across the yaw seam; reduced motion applies the target on the next paint without a transition. No perpetual idle animation or post-release inertia.

The graph JSON, localized link paths, article inventory, edge weights and reasons have not been changed. Tests check the auto-start state with a held fetch, retry, animation cessation, rotation, reset, legend, real drag, actual neighbor count, complete links, no idle draws and theme/visibility lifecycle. Screenshot and public performance verification are still required before claiming visual or timing improvements.

## Editorial palette and motion refinement

The nine category glyphs now use muted forest green, slate blue, copper, plum, brass, dusty rose, olive, teal and graphite drawn around the warm paper/ink theme. Each has an independently contrast-checked light/dark shade. The SVG preview groups same-topic edges by category; legend accents, interactive glyphs, links and tooltip use the same hue. Cross-topic edges remain dashed and neutral until selected. A subtle static radial tint echoes the existing accent; no extra graphics are requested. The view uses a rotation-invariant perspective fit so the graph does not zoom in and out when rotated. Unit tests cover theme contrast, frame-rate-independent easing, exact settle, yaw seam, reduced motion and projection bounds; the browser regression checks actual multi-frame rotation, shared legend/canvas colors, both theme screenshots and idle/offscreen behavior. Measured frame rate and public visual QA remain release evidence, not source claims.
