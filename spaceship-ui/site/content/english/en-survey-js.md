## What is SurveyJS?
- Its free form library lets you build surveys.
    The library is open source and uses the MIT license.
    It's worth checking which license covers the component you plan to use.
    (I'd like to write a short guide to the different licenses.)

- SurveyJS provides survey and quiz forms for JavaScript applications.

## SurveyJS components
As of March 24, 2023, the suite had four components.
1. Form Library
2. Survey Creator
3. Dashboard
4. PDF Generator

## The SurveyJS form library
1. Dynamic form, survey, quiz for JavaScript application
2. Supports React, Vue, Angular, and Knockout.
3. Can integrate Knockout into a jQuery-based web application.
4. SurveyJS offers more than 20 built-in question types,
    including multiple-choice questions, free responses, and rating scales.
5. Conditional branching lets respondents take different paths through a survey.
6. Response validation
    (Built-In Client-Side, Implement Custom Client-Side, Server-Side Validation)
7. Custom interfaces, TypeScript support, and the option to store responses in your own database.

**More about items 2 and 3**
Knockout is a JavaScript library for managing user interfaces in web applications.
It uses the Model–View–ViewModel (MVVM) pattern to keep the interface and data model in sync, making code easier to maintain.
jQuery is a JavaScript library that simplifies HTML document manipulation and event handling.
In item 3, integration means
adding Knockout to a jQuery application to simplify synchronization between the interface and its underlying data.
