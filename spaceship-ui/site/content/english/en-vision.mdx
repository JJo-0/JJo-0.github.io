### RNN

Recurrent neural network

#### Vanishing gradients

[Video explanation](https://www.youtube.com/watch?v=aWInMRtySpQ)

Building a deep neural network often means stacking many hidden layers. The number of layers and their widths affect both performance and complexity. Larger networks generally contain more trainable weights and biases.

**Weights**

- A weight determines how strongly an input contributes to a calculation.
- Each connection multiplies its input by its weight.

**Biases**

- A bias changes how easily a node becomes active.
- Alongside the weights, it adjusts the node's output.

**Backpropagation**

- A loss function measures the error between the output and the target.
- Backpropagation computes how the loss depends on each weight and bias so the optimizer can reduce the error.

**Gradient descent**

- Gradient descent updates the weights and biases in a direction that reduces the loss.
- The learning rate controls the step size and influences how quickly learning proceeds.

<Math display tex={"y = w_1x_1 + w_2x_2 + w_3x_3 + b"} />

Here <Math tex={"w_i"} /> is the weight on input <Math tex={"x_i"} />, and <Math tex={"b"} /> is the bias.

In a deep network, a gradient can shrink as it propagates through many hidden layers. The slope of the activation function enters at every step of backpropagation.

**Sigmoid**

The sigmoid derivative is positive, approaches zero at the extremes, and reaches a maximum of 0.25, or one quarter, at zero.

### MLP

Multilayer perceptron

#### **Understanding the multilayer perceptron**

- The MLP is a foundational machine learning model.
- It is a feedforward neural network with multiple layers.

#### **Overview**

An MLP can learn complex, nonlinear relationships in data. Applications include image recognition, natural language processing, and speech recognition.

#### **History**

The early single-layer perceptron could separate linearly separable data. Real data often have nonlinear boundaries, motivating networks with multiple layers.

Several researchers independently developed ideas behind backpropagation in the early 1970s. Backpropagation became an essential method for training multilayer networks and contributed to the development of deep learning.

#### **2. MLP architecture: layers and neurons**

A typical MLP has an input layer, one or more hidden layers, and an output layer.

The input layer receives raw data, with one input per feature. Hidden layers transform those inputs into new representations. The designer chooses the number of hidden layers and the number of neurons in each as hyperparameters. The output layer produces the prediction. For a multiclass classifier, for example, the number of outputs usually equals the number of classes.<sup>1</sup>

Each neuron multiplies its inputs from the previous layer by their weights, sums them, adds a bias, and applies an activation function. The weights determine the strengths of the connections. The bias shifts the input to the activation function.<sup>1</sup>

In a fully connected MLP, every neuron in one layer connects to every neuron in the next.<sup>1</sup> These connections support complex patterns, but the number of weights and biases can raise computational cost and the risk of overfitting.<sup>3</sup>

**3. Training an MLP with backpropagation**

Supervised learning uses labeled examples to learn a relationship between inputs and outputs.<sup>1</sup> During the forward pass, an input moves through the layers to produce a prediction.<sup>1</sup> A loss function compares that prediction with its target.<sup>8</sup> Common losses include mean squared error for regression and cross-entropy for classification.<sup>13</sup>

During the backward pass, backpropagation uses the chain rule to compute the gradient of the loss with respect to each weight and bias.<sup>2</sup> An optimizer updates the parameters in a direction that reduces the loss.<sup>1</sup> The learning rate controls the size of each update.<sup>1</sup> Options include gradient descent, stochastic gradient descent (SGD), and Adam.<sup>2</sup> Computing all the parameter gradients efficiently makes it practical to train deep MLPs and learn internal features that would otherwise need manual feature engineering.<sup>2</sup>

**4. Activation functions introduce nonlinearity**

An activation function acts on each neuron's weighted sum. Nonlinear activations let an MLP model complex relationships.<sup>1</sup> Without them, a stack of affine layers reduces to one affine transformation.<sup>2</sup> Common choices include:

- **Sigmoid** maps values into the interval from 0 to 1. It was common in early hidden layers and is still used in binary classification outputs. ReLU has largely displaced it in hidden layers.<sup>2, 13</sup>
- **tanh** maps inputs into the interval from −1 to 1.<sup>1</sup>
- **ReLU (rectified linear unit)** passes positive inputs through and returns zero for negative inputs.<sup>1</sup> It is inexpensive to compute and helps reduce vanishing gradients, but a unit can become inactive and stop learning, the “dying ReLU” problem.<sup>24</sup>
- **Softmax** produces a distribution over classes and is common in multiclass output layers.<sup>1</sup>

Other choices include Leaky ReLU and Softplus.<sup>2</sup> The appropriate function depends on the task and the layer.<sup>1</sup> Moving from the Heaviside step function of early perceptrons to activations with useful derivatives, such as sigmoid or the piecewise-linear ReLU, made gradient-based training practical.<sup>2</sup>

**6. Strengths and limitations**

An MLP can approximate nonlinear functions and learn complex relationships.<sup>1</sup> Through its hidden layers it can learn hierarchical features directly from raw inputs.<sup>12</sup> MLPs can handle many application areas, with appropriate preprocessing for numerical and categorical features and missing values.<sup>12</sup> Hardware and optimization advances make larger datasets and architectures feasible.<sup>12</sup> After training, inference can be fast.<sup>6</sup> Some tasks yield reasonable accuracy with relatively small datasets, and online learning can update a model incrementally.<sup>7</sup>

Small datasets and overly complex architectures increase the risk of overfitting.<sup>6</sup> Deep models can suffer vanishing or exploding gradients.<sup>8</sup> Results are sensitive to hyperparameters such as the learning rate and layer sizes.<sup>12</sup> Training a deep MLP can consume substantial computing resources<sup>6</sup> and time.<sup>25</sup> Its predictions can be difficult to explain.<sup>25</sup> Dense connections increase parameter count and can create redundant units. Performance depends on how effectively the network was trained.<sup>6</sup> An MLP also provides little direct information about the size of each input variable's effect on the outcome.<sup>31</sup> Its expressive capacity and susceptibility to overfitting make regularization and hyperparameter tuning important.<sup>12</sup>

**7. Comparing MLPs, CNNs, and RNNs**

Convolutional neural networks (CNNs) use local connections and shared weights, making them efficient for spatial data such as images.<sup>1</sup> They can exploit spatial relationships directly.<sup>3</sup> A conventional MLP takes a feature vector, whereas a CNN operates on a spatial tensor.<sup>3</sup> The MLP is a general-purpose architecture. For an image task, dense layers typically require more parameters than convolutional layers.<sup>3</sup>

A recurrent neural network (RNN) uses recurrence to process a sequence, while the MLP feeds its input forward through its layers.<sup>1</sup> RNNs suit ordered data such as time series and language.<sup>1</sup> An MLP can take a flattened sequence, but recurrence typically offers a better way to represent temporal dependencies.<sup>20</sup> The performance and efficiency gains from CNNs and RNNs illustrate why the structure of the network should suit the structure of the data.<sup>3</sup>

**8. Research directions**

Researchers continue to study MLPs in medicine, engineering, and the social sciences.<sup>10</sup> Hybrid systems combine MLPs with CNNs or RNNs.<sup>2</sup> Other work improves learning algorithms and addresses vanishing and exploding gradients,<sup>8</sup> or explores new layers and connectivity patterns, as in MLP-Mixer.<sup>2</sup>

Applications include information diffusion, analysis of neurodevelopmental conditions, slope stability, and medical diagnosis.<sup>10</sup> Researchers also combine MLPs with other machine learning or statistical methods,<sup>10</sup> and optimize their implementation for GPUs and other hardware.<sup>33</sup> Alongside specialized deep learning architectures, work on MLPs continues to improve performance, efficiency, and applicability to complex problems, often in combination with other techniques.<sup>10</sup>

**9. Conclusion**

The multilayer perceptron remains a foundational model in neural networks and deep learning. Its nonlinear modeling capabilities support tasks from image recognition and natural language processing to time-series prediction. MLPs remain active research tools both as stand-alone predictors and as components in systems built with CNNs and RNNs.

### ViT

ViT stands for *vision transformer*. It applies the transformer architecture to image recognition. A useful prerequisite is *Attention Is All You Need*, including the mathematics and concepts behind the transformer. Originally widely used for natural language processing, the architecture also performs well in vision.

A ViT divides an image into small **patches** and uses each patch as an input token. Like words in a language sequence, patches can attend to one another. Self-attention learns relationships between patches, giving the model access to the context of the entire image for tasks such as classification and object detection.

#### **Semi-Supervised Classification with Graph Convolutional Networks**

**What is semi-supervised learning?**

It uses labeled and unlabeled examples together. Labels can be costly and scarce. A model learns patterns from the labeled examples and can use similarity and structural relationships to infer labels for other observations. Label propagation is one way to exploit those relationships.

**What is a GCN?**

A GCN is designed for graph-structured data. Neighborhoods come from the graph's edges. Other familiar data structures include image grids and time-ordered sensor readings.
