## 📚 What is a data structure?

_A typical programming process_

1. Understand and analyze the problem
2. Design the program variables
3. Design the program logic (algorithms and flowcharts)
4. Write the program
5. Run and debug the program

Data structures belong to the **design of program variables**:
1. identify data objects and their attributes;
2. define and implement relationships between data and the operations on them.
They provide systematic and efficient methods for doing so.

Data types used in data structures

|Data type|Set of data objects|Example operations|Internal representation|
|:--:|:--|:--:|:--:|
|Integer|Numbers without a fractional part|+, -, \*, /, %, ++, --, (and others) |Fixed-point representation|
|Real number|Numbers with a fractional part|+, -, \*, /, %, ++, --, (and others) |Floating-point representation|
|Character|The character set defined by the computer system|+, -, <, >, (and others)|ASCII representation| 
|Array|A collection of values of the same type|x[i]|Sequential representation of homogeneous objects|
|Structure|A collection of values of different types|x.member|Sequential representation of heterogeneous objects|

## 📚 Classification of data structures

1. Data types provided by a programming language (basic representations of data objects)
* Simple types: integer, real, character, Boolean and pointer types
* Structured types: arrays, structures, strings and others
2. Structures studied in a data structures course (representations for managing sets of data objects)
* Linear list structures
  * Sequential list: an ordered list implemented using sequential mapping
  * Linked list: an ordered list implemented using nonsequential mapping
  * Stack: a last-in, first-out (LIFO) list
  * Queue: a first-in, first-out (FIFO) list
* Nonlinear structures
  * Trees and binary trees: binary search trees, m-way search trees, heaps and others
  * Graphs: directed graphs, undirected graphs and others
  * Hash tables
  * Index trees: AVL trees, B trees, B+ trees, red-black trees and others

## 📚 Data structures in C (libraries)
C does not directly provide the data structures discussed here, so they must be implemented to use them.
Third-party libraries do provide these data structures.

One is **GLib**.  
(Take care not to confuse it with glibc.)

**GLib and glibc compared**

||GLib|glibc|
|:--:|:--|:--|
|Data structures|Arrays, queues, linked lists, hash tables, trees and others|Queues, lists, trees and others|
|Object system|GObject|-|
|IO|iostream, file input/output|fopen, fwrite, fread, fclose and others|
