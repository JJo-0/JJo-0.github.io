An inspection camera says “left” when it sees a yellow part. Give it a one-line routing instruction and it says “right” for the same photograph. Where did that change take place? The weights in the saved model file could be identical before and after. Clear the instruction and start a fresh run, and the answer could revert. Both observations can hold at once.

[Chapter 23](/en/posts/self-improving-ai-23-self-edits-and-meta-learning/) asked <strong>which learning rule to learn</strong> across tasks. Part II, pages 51–55, now asks <strong>what that rule writes, and where, during a single sequence</strong>. We follow the inner weights of a TTT layer, the neural memory in Titans, and the values a Transformer retrieves from context. The tokens, cameras and routing instructions used in the calculations are teaching examples.

Sun and colleagues give this interpretation a concrete implementation. They use the <strong>weights W of a small predictor</strong> as the hidden state. Read the three update rules in the middle panel. A simple recurrent neural network (RNN) changes its state vector. Self-attention appends a key and a value to a list. A test-time training (TTT) layer subtracts a loss gradient scaled by a learning rate from W. The output equations in the lower panel show how each layer reads its updated state. Lee's analogy applies across the rows. The TTT row explicitly builds a self-supervised gradient step into the forward pass. [ICML 2025 paper, Figure 2](https://raw.githubusercontent.com/mlresearch/v267/main/assets/sun25h/sun25h.pdf#page=3)

### Worked example 1. What does one token write to the weights, and what does it read?

Equations 3 and 4 in the paper project the current token representation xₜ into three views. The key kₜ supplies the <strong>input to the small predictor</strong>. The value vₜ supplies the <strong>target features to reconstruct</strong>. The query qₜ supplies the <strong>features used to read the updated predictor</strong>. All three come from the current token, so the layer can take its inner step before the next word arrives. The outer loop learns the three projection matrices. [Paper, Equations 3–4](https://raw.githubusercontent.com/mlresearch/v267/main/assets/sun25h/sun25h.pdf#page=4)

<Math tex={String.raw`k_t=\theta_K x_t,\qquad v_t=\theta_V x_t,\qquad q_t=\theta_Q x_t.`} display />


For a calculation by hand, make the small predictor a single multiplication, f(k; w)=wk. Scale the squared reconstruction error by ½ so that the factor of two cancels in its derivative. Start with weight 0 and learning rate η=½. Suppose token A supplies (k,v,q)=(1,2,2). Its prediction before the update is 0 and its target is 2.

<Math tex={String.raw`\ell(w)=\tfrac12(wk-v)^2,\qquad \frac{d\ell}{dw}=(wk-v)k.`} display />

<Math tex={String.raw`g_A=(0\cdot1-2)\cdot1=-2,\qquad w_1=0-\tfrac12(-2)=1.`} display />

<Math tex={String.raw`\ell(0)=2,\qquad \ell(1)=\tfrac12,\qquad z_1=w_1 q=1\cdot2=2.`} display />


The last line measures reconstruction on the <strong>key, 1</strong>, then reads the layer output z₁ on the <strong>query, 2</strong>. The output is a feature that travels onward through the network. The language model still has to turn it into a distribution over next tokens. We have left out bias and normalization and evaluated a fresh gradient for each token. The paper also introduces mini-batches of tokens so a device can evaluate several gradients in parallel. [Paper, §2.4 and Figure 3](https://raw.githubusercontent.com/mlresearch/v267/main/assets/sun25h/sun25h.pdf#page=4)

### Worked example 2. Can two tokens in a different order change the next-word probability?

Give token B target −2 and keep the key at 1 and the query at 2 for both tokens. Restart at w₀=0 for each sequence, then use the same update as above. Each new weight lies halfway between the previous weight and the incoming target.

<Math tex={String.raw`w_t=w_{t-1}-\tfrac12(w_{t-1}-v_t)=\tfrac12 w_{t-1}+\tfrac12 v_t.`} display />


| Reading order | After writing the first token | After writing the second token | Final output z₂=2w₂ |
|---|---:|---:|---:|
| A → B | 1 | (1−2)/2 = −0.5 | −1 |
| B → A | −1 | (−1+2)/2 = 0.5 | 1 |

Now build a toy language model with two possible next words. Assign z₂ as the logit for word C and set the other word's logit to 0. Suppose the correct next word happens to be C for both sequences. Applying softmax gives the probability assigned to C. Its negative natural logarithm gives the next-token loss.

<Math tex={String.raw`p(C)=\frac{e^{z_2}}{1+e^{z_2}},\qquad L_{\rm next}=-\ln p(C).`} display />

<Math tex={String.raw`\begin{aligned}p(C\mid AB)&\approx0.269,& L_{AB}&\approx1.313,\\p(C\mid BA)&\approx0.731,& L_{BA}&\approx0.313.\end{aligned}`} display />


The later target has a larger influence on the final w. The <strong>inner loss ℓ</strong> scores reconstruction of v from the current token. The <strong>outer loss L</strong> scores the probability given to the actual next word after the layer has stored that context. During training the outer loss teaches the projections and the rest of the language model how to use this memory. At deployment the layer can update W for a new sentence from the tokens of that sentence alone. [Paper, §2.2 on the two learning loops](https://raw.githubusercontent.com/mlresearch/v267/main/assets/sun25h/sun25h.pdf#page=3)

On page 11 of that deck, H₁ is computed from H₀ and x₁. When the layer computes H₂, there is no direct arrow from x₁. Its contribution travels through H₁. Page 17 traces a different route. ### Worked example 3. What do we store and read at token four and token eight?

Take one attention head with two numbers per key and two per value. Each position can attend to every earlier position and itself. Just before producing the output at position t, the cache holds t pairs. The current query scores each key once. For comparison, give our linear TTT layer a single bias-free matrix W that maps two-dimensional keys into two-dimensional values.

<Math tex={String.raw`N_{\rm KV}(t)=t(2+2)=4t,\qquad N_W=2\times2=4.`} display />


| Current position | Numbers in the KV cache | Query–key dot products at this position | Numbers in the linear TTT state W |
|---|---:|---:|---:|
| Token 4 | 16 | 4 | 4 |
| Token 8 | 32 | 8 | 4 |

TTT has its own cost for updating W and computing Wq at each token. The table counts <strong>state carried across positions</strong> and <strong>keys scored by a query</strong>. Wall-clock time and total GPU memory also depend on the layer width, model weights, temporary arrays and parallel execution. A fixed-size state compresses the past. For instance, under our scalar update, target sequences (2,−2) and (0,−1) both leave a final weight of −0.5. Reading that weight alone cannot recover which pair occurred. The paper's long-context experiment evaluates the information that survives compression by measuring perplexity on next-token prediction. Lower perplexity means a higher geometric mean probability for the observed next tokens. On the right of Figure 1, under matched training compute, TTT-Linear and TTT-MLP keep reducing perplexity beyond 16k tokens of context. The Mamba curve stops improving in that experiment. [TTT paper, long-context experiment in Figure 1](https://raw.githubusercontent.com/mlresearch/v267/main/assets/sun25h/sun25h.pdf#page=2) · [State and computational cost in Figure 2](https://raw.githubusercontent.com/mlresearch/v267/main/assets/sun25h/sun25h.pdf#page=3)

The upper diagram shows one of the three Titans designs, <strong>memory as a context (MAC)</strong>. When a segment arrives, the model retrieves information from its neural memory. ### Worked example 4. Why does the previous update matter for the very same token?

<LearningFigure
  src="/assets/posts/self-improving-ai-24-learning-inside-the-hidden-state/titans-surprise-and-forgetting.png"
  alt="A waterfall chart adds the retained weight (1.80), the previous update (0.20), and the current error term (0.50) to reach 2.50."
  caption="An illustrative scalar step through Titans Equations 12–14, showing the contributions of the old memory, the previous update and the new token."
  source="https://arxiv.org/pdf/2501.00663v1#page=6"
  credit="JJo illustration · based on Ali Behrouz, Peilin Zhong and Vahab Mirrokni"
  label="Supplementary material"
  width={1800} height={1147}
/>

In Titans, <strong>surprise</strong> has a magnitude and a direction. Each token supplies a key k and a value v. The memory tries to recover v from k. To work through Equation 12, take an <strong>illustrative scalar memory</strong> that multiplies its key by a weight m. Suppose m=2, the new key is k=1 and the target is v=3. Its output is 2. Increasing m would move the output toward 3. [Titans, Equations 11–14](https://arxiv.org/pdf/2501.00663v1#page=6)

<Math tex={String.raw`\ell(m)=(mk-v)^2,\qquad g=2(mk-v)k=2(2-3)=-2.`} display />


Write S for the previous update and S′ for the new one. The coefficient η carries part of the previous update forward, θ scales the current gradient, and α discounts the old memory itself. In the paper, these coefficients can depend on the input. For this one step, take S=0.4, η=0.5, θ=0.25 and α=0.1.

<Math tex={String.raw`S'=\eta S-\theta g=0.5(0.4)-0.25(-2)=0.70.`} display />

<Math tex={String.raw`m'=(1-\alpha)m+S'=0.9(2)+0.70=2.50.`} display />


The bars account for every part of the new weight. The old memory contributes 1.80, the previous update contributes 0.20 and the current error contributes 0.50. Reading the same key now returns 2.5, bringing the squared error down from 1 to 0.25. Dropping only the previous update by setting η=0 gives 2.30. Turning off only the forgetting gate by setting α=0 gives 2.70. The two coefficients act on different quantities. The authors also tested these components separately. Their base neural memory (LMM) scored 92.68% on the long-context accuracy column of Table 5, compared with 87.12% after removing momentum and 85.60% after removing weight decay. These differences describe that particular ablation. [Titans, Section 5.9 and Table 5](https://arxiv.org/pdf/2501.00663v1#page=17)

### Worked example 5. How many writes do three memories make in eight tokens?

Read the lower diagram horizontally and you see RNN and attention layers arranged in sequence. The authors add another axis. <strong>Which quantity updates, on what signal, and how often?</strong> This is the perspective of Nested Learning. One concrete design, the <strong>continuum memory system (CMS)</strong>, passes each input through several multilayer perceptrons (MLPs). Each block updates its weights at the end of its own token chunk. A block can therefore process a token even when its weights stay fixed for that step. [Nested Learning, Figure 2](https://arxiv.org/pdf/2512.24695v1#page=4) · [Section 7.1, Equations 70–71](https://arxiv.org/pdf/2512.24695v1#page=27)

<LearningFigure
  src="/assets/posts/self-improving-ai-24-learning-inside-the-hidden-state/nested-learning-write-intervals.png"
  alt="Over eight tokens, three blocks with write intervals of one, two and four tokens update their weights eight, four and two times."
  caption="Illustrative CMS schedule based on Nested Learning Equations 70–71. A filled cell marks a weight update after processing that token."
  source="https://arxiv.org/pdf/2512.24695v1#page=27"
  credit="JJo illustration · based on Ali Behrouz et al."
  label="Supplementary material"
  width={1800} height={1102}
/>

For an <strong>illustrative schedule</strong>, let the three write intervals C be 1, 2 and 4 tokens. Number the first token 1 and write only at the end of a complete chunk. The number of writes N in a sequence of length T is the number of complete chunks.

<Math tex={String.raw`N(T,C)=\left\lfloor T/C\right\rfloor,\qquad (N(8,1),N(8,2),N(8,4))=(8,4,2).`} display />


All three blocks write after tokens 4 and 8. Only the fastest block writes after token 7. The slowest block still processes token 7 and can produce a different output for it, using the same weights it has held since the end of token 4. A write every four tokens therefore allows an output at every token. The schedule specifies how often weights can change. How long a particular association survives also depends on what was written and how later writes interfere with it. [Nested Learning, Equations 70–71](https://arxiv.org/pdf/2512.24695v1#page=27)

## Part II, page 54 — What can a change in the answer tell us?

<LearningFigure
  src="/assets/posts/self-improving-ai-24-learning-inside-the-hidden-state/ntu-54-english.png"
  alt="The upper row connects three brains and the lower row connects three networks. Changing colors mark successive stages."
  caption="Part II, page 54. A different answer for the same input is observable. A separate test can locate the effect."
  source="https://speech.ee.ntu.edu.tw/~hylee/ml/ml2026-course-data/self-evolving-agent.pdf#page=54"
  credit="Hung-yi Lee / NTU ML 2026"
  width={1800} height={1013}
/>

The slide has two rows. In the top row, the brain changes color as a person gains experience. In the bottom row, a network changes color across stages of training. Lee starts with this familiar analogy. It helps separate an observation, “the system changed its behavior,” from one possible explanation, “training changed its weights.” If a model gave a different answer yesterday, we also need to know what information it could read on each occasion. [Lecture at 48:42](https://www.youtube.com/watch?v=cQLKVzbwN7I&t=2922s) · [The analogy with brain connections at 49:17](https://www.youtube.com/watch?v=cQLKVzbwN7I&t=2957s)

Consider a factory where workers reassign the sorting bins between shifts. Today's instruction says “blue goes left, yellow goes right.” The inspector already recognizes colors. What it needs to learn is <strong>which bin goes with which color today</strong>. Here we can separate color recognition, which the inspector brings to the shift, from the information supplied by the instruction.

### Worked example 6. How much of the improvement survives a reset?

Take two photographs of blue parts and two of yellow parts. Test each photograph independently. Keep the four images, saved weights, readout rule and correct routes fixed. Suppose the inspector sends everything left before it sees the instruction and routes all four parts correctly while it can read the instruction. For the final condition, restart from the original checkpoint with a fresh context and empty runtime state. The outcomes below are hypothetical.

| Condition on the same four photographs | Two blue parts | Two yellow parts | Correct under today's assignment |
|---|---|---|---|
| Before receiving the instruction | Left twice | Left twice | 2/4 |
| With the instruction in context | Left twice | Right twice | 4/4 |
| Fresh run from the original checkpoint | Left twice | Left twice | 2/4 |

<Math tex={String.raw`A_{\rm before}=\frac24=0.50,\qquad A_{\rm context}=\frac44=1,\qquad A_{\rm reset}=\frac24=0.50.`} display />


Subtract the initial accuracy separately from the score while the instruction is present and from the score after the reset. A difference between accuracies is measured in percentage points.

<Math tex={String.raw`\Delta_{\rm present}=1-0.50=0.50,\qquad \Delta_{\rm retained}=0.50-0.50=0.`} display />


The instruction buys <strong>50 percentage points</strong> on these images. The improvement still observable in the fresh run is <strong>zero points</strong>. The first two rows measure the behavioral effect of having the instruction available. The third tests whether that effect survives this particular reset. If a deployed system can read a conversation log or an external memory, record whether the fresh run can retrieve the instruction again. A real example of adaptation with fixed model weights is Brown et al.'s 2020 GPT-3 evaluation, in which demonstrations in the text specified the task. [GPT-3, §2, task presentation](https://proceedings.neurips.cc/paper/2020/file/1457c0d6bfcb4967418bfb8ac142f64a-Paper.pdf#page=3)

### Worked example 7. Why does the attention output change sign for the same image?

Focus on one blue part. Write the instruction as two entries, one for blue and one for yellow. Suppose the image's query has scaled scores of ln 3 and zero against their respective keys. The scaling for the key dimension is already included. Softmax exponentiates the scores and divides by their sum. [Vaswani et al., 2017, equation 1](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=4)

<Math tex={String.raw`(a_{\rm blue},a_{\rm yellow})=\frac{(e^{\ln 3},e^0)}{e^{\ln 3}+e^0}=\left(\frac34,\frac14\right).`} display />


The fraction 3/4 is the <strong>weight on the blue entry</strong>. Encode left as +1 and right as −1, then take the weighted sum of the two values. In this toy representation, colors determine keys and directions determine values. When the next shift swaps the two directions, the query and keys stay the same and the two values change sign.

<Math tex={String.raw`z_{\rm today}=\tfrac34(+1)+\tfrac14(-1)=+\tfrac12,\qquad z_{\rm next}=\tfrac34(-1)+\tfrac14(+1)=-\tfrac12.`} display />
