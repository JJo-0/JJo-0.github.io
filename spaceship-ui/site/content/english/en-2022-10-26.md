## Why databases are needed

* Definition of a database
An **integrated**, **stored** collection of **operational** data that multiple users in an organization can **share**.

---

|Term|Definition|
|:--:|--:|
|Data|Facts or values collected by observing or measuring the world|
|Information|Processed data that can inform a decision|
|Information processing|A process or method for extracting information from data|
|Information system|Collects and stores the data an organization needs and turns it into useful information on demand|
|Database|Stores data within an information system and supplies it when needed|

## Classifying data

* By structure
  * Structured data
    * Data with an explicit, predefined structure\
    Examples include Excel spreadsheets and relational database tables.
  * Semi-structured data
    * The data carries markers that describe its own structure.\
    Examples include HTML, XML, and JSON documents used to exchange information on the web, web logs, and sensor records.
  * Unstructured data
    * Data stored without a predefined structure\
    Examples include social media text, video, and images.\
___
* By the values a variable can take
  * Categorical data\
  Values identify a group or category.
    * Nominal data\
    Categories have no inherent ordering.\
    Examples include blood type, sex, academic department, place of residence, and MBTI type.
    * Ordinal data\
    Categories have a meaningful ordering.\
    Examples include school year, letter grade, and membership tier.
  * Numerical data\
  Values are numbers that support comparisons of magnitude and arithmetic operations.
    * Discrete data
    Values occur in separate, countable steps.\
    Examples include the number of customers, units sold, and applicants admitted.
    * Continuous data\
    Values can vary along a continuous scale.\
    Examples include height, weight, temperature, and scores measured on a continuous scale.\
___
* Qualitative and quantitative data
  * Qualitative data\
  Unstructured descriptions of people's views and assessments.
  * Quantitative data\
  Structured representations of objective measurements using numbers, shapes, or symbols.
