A norm assigns a number to the <strong>magnitude</strong> of a vector or matrix. Norms are fundamental in linear algebra and recur in machine learning loss functions, regularization, and optimization constraints.

## 1. What is a norm?

A norm measures the size of a vector or matrix. The most familiar example is the Euclidean norm, also called the ℓ₂ norm.

<Math display label="L2 norm" tex={"\\|\\mathbf{x}\\|_2 = \\sqrt{\\sum_{i=1}^{N} x_i^2}"} />

Its square can be expressed as an inner product.

<Math display label="Squared L2 norm" tex={"\\|\\mathbf{x}\\|_2^2 = \\mathbf{x}^{\\top}\\mathbf{x}"} />

## 2. Properties of a norm

A function <Math tex={"f : \\mathbb{R}^N \\to \\mathbb{R}"} /> must satisfy the following four conditions to be a norm.

1. **Non-negativity**

<Math display tex={"\\forall \\mathbf{x} \\in \\mathbb{R}^N,\\quad f(\\mathbf{x}) \\ge 0"} />

2. **Definiteness**

<Math display tex={"f(\\mathbf{x}) = 0 \\iff \\mathbf{x} = \\mathbf{0}"} />

3. **Absolute homogeneity**

<Math display tex={"\\forall t \\in \\mathbb{R},\\quad f(t\\mathbf{x}) = |t|f(\\mathbf{x})"} />

4. **Triangle inequality**

<Math display tex={"f(\\mathbf{x}+\\mathbf{y}) \\le f(\\mathbf{x}) + f(\\mathbf{y})"} />

## 3. Common vector norms

### ℓ₁ norm (Manhattan norm)

<Math display label="L1 norm" tex={"\\|\\mathbf{x}\\|_1 = \\sum_{i=1}^{N} |x_i|"} />

Sum the absolute values of the components. ℓ₁ regularization can drive some coefficients exactly to zero, making it a common choice when sparsity is desirable.

### ℓ∞ norm (maximum norm)

<Math display label="L infinity norm" tex={"\\|\\mathbf{x}\\|_{\\infty} = \\max_i |x_i|"} />

Take the largest absolute component as the magnitude of the vector.

### The general ℓₚ norm

<Math display label="Lp norm" tex={"\\|\\mathbf{x}\\|_p = \\left(\\sum_{i=1}^{N} |x_i|^p\\right)^{1/p},\\qquad p \\ge 1"} />

- At p = 1, this is the ℓ₁ norm.
- At p = 2, this is the ℓ₂ norm.
- As p approaches infinity, it converges to the ℓ∞ norm.
- For 0 < p < 1, the expression fails the triangle inequality and therefore does not define a norm.

## 4. A matrix norm: the Frobenius norm

Matrices also admit norms. One example is the Frobenius norm.

<Math display label="Frobenius norm" tex={"\\|\\mathbf{A}\\|_F = \\sqrt{\\sum_{i=1}^{M}\\sum_{j=1}^{N} A_{i,j}^2} = \\sqrt{\\operatorname{tr}(\\mathbf{A}^{\\top}\\mathbf{A})}"} />

It equals the ℓ₂ norm of the long vector formed by stacking all matrix entries. Common uses include measuring the size of a matrix difference, low-rank approximation, and analyzing neural network weights.

## 5. Uses in machine learning

- **ℓ₁ regularization** encourages sparse parameters.
- **ℓ₂ regularization / weight decay** penalizes large weights to reduce overfitting.
- **MSE and distance-based losses** are closely related to ℓ₂ distance.
- **MAE** is related to ℓ₁ distance.
- **Optimization constraints** often bound the norm of a parameter vector or perturbation.

## Summary

Norms give a consistent definition of size for vectors and matrices. Choosing ℓ₁, ℓ₂, or ℓ∞ changes the geometry of an optimization problem and can change the resulting model. These tools recur in distance calculations, regularization, loss functions, and robustness analysis.
