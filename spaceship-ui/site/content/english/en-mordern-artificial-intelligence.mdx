## 2. AI, ML, and DL are different terms

Broadly, **artificial intelligence** concerns building systems that behave intelligently. **Machine learning** learns rules or representations from data within that field. **Deep learning** is a machine-learning family centered on multilayer neural networks.

In one line:

**Artificial intelligence ⊃ Machine learning ⊃ Deep learning**

This inclusion diagram is not a complete law of the field's history. Rule-based AI, search, planning, and optimization can be non-learning approaches, while modern systems combine learned models with search, tools, external memory, and planners. It provides a starting view of field relationships rather than a complete account of contemporary architectures.

## 4. Image processing and computer vision

The lecture presents the imaging pipeline as follows.

> Physical scene → Image formation → Raw measurements → Image processing → Improved image → Image analysis → Meaningful decisions

Two additional branches accompany this pipeline.

- Image display: representing images for human viewing
- Image compression: reducing storage and transmission costs

Traditionally, image processing was often called **low-level vision**, and image analysis **high-level vision**. Deep learning has weakened this boundary: one network can jointly learn restoration, feature extraction, detection, and classification.

### Low-level and high-level perspectives

| Perspective | Low-level emphasis | High-level emphasis |
|---|---|---|
| Main question | How should pixels be restored or transformed? | What is in the scene, and what does it mean? |
| Typical tasks | Denoising, super-resolution, restoration, calibration | Classification, detection, segmentation, tracking, reasoning |
| Traditional foundations | Signal processing, optimization, statistics | Pattern recognition, machine learning |
| Modern characteristic | Substantial overlap | Substantial overlap |

## 5. An important caution from the lectures

One central message is that fundamental understanding of modern deep learning remains immature.

Better model performance differs from **fully understanding why models generalize, what representations they learn, and when they fail**. This motivates the linear algebra, probability, and optimization that follow.

## Part 1.1: Linear Algebra I — Vectors, Matrices, and Products

### 1. Why begin with linear algebra?

Most modern neural networks ultimately execute **operations on vectors and matrices**. Linear algebra is more than a prerequisite: it connects forward passes, matrix representations of convolution, attention, optimization, and covariance calculations.

#### 1.1 A two-variable linear system

The lectures provide the following two equations. The second contains `x_2` twice in the source. We **preserve that notation** and give a conventional two-variable system immediately below.

{/* formula: MAI2-001 */}
<Math formulaId="MAI2-001" display tex={"\\begin{aligned}\nA_{1,1}x_1 - A_{1,2}x_2 &= b_1,\\\\\nA_{2,1}x_2 - A_{2,2}x_2 &= b_2.\n\\end{aligned}"} />
A general two-variable linear system is usually written as follows.

{/* formula: MAI2-002 */}
<Math formulaId="MAI2-002" display tex={"\\begin{aligned}\nA_{1,1}x_1 + A_{1,2}x_2 &= b_1,\\\\\nA_{2,1}x_1 + A_{2,2}x_2 &= b_2.\n\\end{aligned}"} />
Matrix notation makes it much more compact.

{/* formula: MAI2-003 */}
<Math formulaId="MAI2-003" display tex={"A\\mathbf{x}=\\mathbf{b},\\qquad\nA=\\begin{bmatrix}A_{1,1}&A_{1,2}\\\\A_{2,1}&A_{2,2}\\end{bmatrix},\\qquad\n\\mathbf{b}=\\begin{bmatrix}b_1\\\\b_2\\end{bmatrix}."} />
### 2. Basic notation

Always check column-vector and matrix dimensions first.

{/* formula: MAI2-004 */}
<Math formulaId="MAI2-004" display tex={"\\mathbf{x}\\in\\mathbb{R}^{M},\\qquad \\mathbf{x}^{T}\\ \\text{is a row vector}."} />
{/* formula: MAI2-005 */}
<Math formulaId="MAI2-005" display tex={"A\\in\\mathbb{R}^{M\\times N}."} />
{/* formula: MAI2-006 */}
<Math formulaId="MAI2-006" display tex={"\\mathbf{x}=\n\\begin{bmatrix}\nx_1\\\\x_2\\\\\\vdots\\\\x_M\n\\end{bmatrix}."} />
{/* formula: MAI2-007 */}
<Math formulaId="MAI2-007" display tex={"A=\n\\begin{bmatrix}\nA_{1,1}&A_{1,2}&\\cdots&A_{1,N}\\\\\nA_{2,1}&A_{2,2}&\\cdots&A_{2,N}\\\\\n\\vdots&\\vdots&\\ddots&\\vdots\\\\\nA_{M,1}&A_{M,2}&\\cdots&A_{M,N}\n\\end{bmatrix}."} />
Columnwise and rowwise notation are also common.

{/* formula: MAI2-008 */}
<Math formulaId="MAI2-008" display tex={"A=\\begin{bmatrix}\\mathbf{a}_1&\\mathbf{a}_2&\\cdots&\\mathbf{a}_N\\end{bmatrix}."} />
{/* formula: MAI2-009 */}
<Math formulaId="MAI2-009" display tex={"A=\\begin{bmatrix}\n\\mathbf{a}_1^T\\\\\n\\mathbf{a}_2^T\\\\\n\\vdots\\\\\n\\mathbf{a}_M^T\n\\end{bmatrix}."} />
### 3. Vectorizing an image

Flattening a multidimensional image into one long vector allows operations such as convolution to be expressed as matrix–vector multiplication.

{/* formula: MAI2-010 */}
<Math formulaId="MAI2-010" display tex={"\\begin{bmatrix}y_1&\\cdots&y_N\\end{bmatrix}\n\\longrightarrow\n\\begin{bmatrix}y_1\\\\\\vdots\\\\y_N\\end{bmatrix}."} />
{/* formula: MAI2-011 */}
<Math formulaId="MAI2-011" display tex={"y[m,n]=(a*x)[m,n]."} />
{/* formula: MAI2-012 */}
<Math formulaId="MAI2-012" display tex={"\\mathbf{y}=A\\mathbf{x}."} />
### 4. Vector–vector products

#### 4.1 Inner product

An inner product reduces two vectors to one scalar.

{/* formula: MAI2-013 */}
<Math formulaId="MAI2-013" display tex={"\\mathbf{x}^T\\mathbf{y}\n=\n\\begin{bmatrix}x_1&x_2&\\cdots&x_N\\end{bmatrix}\n\\begin{bmatrix}y_1\\\\y_2\\\\\\vdots\\\\y_N\\end{bmatrix}\n=\n\\sum_{i=1}^{N}x_i y_i\\in\\mathbb{R}."} />
{/* formula: MAI2-014 */}
<Math formulaId="MAI2-014" display tex={"\\mathbf{x}^T\\mathbf{y}=\\mathbf{y}^T\\mathbf{x}."} />
#### 4.2 Outer product

An outer product forms a matrix from two vectors.

{/* formula: MAI2-015 */}
<Math formulaId="MAI2-015" display tex={"\\mathbf{x}\\mathbf{y}^T\n=\n\\begin{bmatrix}\nx_1y_1&x_1y_2&\\cdots&x_1y_N\\\\\nx_2y_1&x_2y_2&\\cdots&x_2y_N\\\\\n\\vdots&\\vdots&\\ddots&\\vdots\\\\\nx_My_1&x_My_2&\\cdots&x_My_N\n\\end{bmatrix}\n\\in\\mathbb{R}^{M\\times N}."} />
### 5. Two views of matrix–vector multiplication

Rowwise, each output component is the inner product of one matrix row with the input vector.

{/* formula: MAI2-016 */}
<Math formulaId="MAI2-016" display tex={"\\mathbf{y}=A\\mathbf{x}\n=\n\\begin{bmatrix}\n\\mathbf{a}_1^T\\mathbf{x}\\\\\n\\mathbf{a}_2^T\\mathbf{x}\\\\\n\\vdots\\\\\n\\mathbf{a}_M^T\\mathbf{x}\n\\end{bmatrix}."} />
{/* formula: MAI2-017 */}
<Math formulaId="MAI2-017" display tex={"y_i=\\mathbf{a}_i^T\\mathbf{x}."} />
Columnwise, the output is a linear combination of A's columns.

{/* formula: MAI2-018 */}
<Math formulaId="MAI2-018" display tex={"\\mathbf{y}=A\\mathbf{x}\n=\n\\begin{bmatrix}\\mathbf{a}_1&\\mathbf{a}_2&\\cdots&\\mathbf{a}_N\\end{bmatrix}\n\\begin{bmatrix}x_1\\\\x_2\\\\\\vdots\\\\x_N\\end{bmatrix}\n=\n\\mathbf{a}_1x_1+\\mathbf{a}_2x_2+\\cdots+\\mathbf{a}_Nx_N."} />
A row vector can also multiply from the left.

{/* formula: MAI2-019 */}
<Math formulaId="MAI2-019" display tex={"\\mathbf{y}^T=\\mathbf{x}^T A\n=\n\\begin{bmatrix}\n\\mathbf{x}^T\\mathbf{a}_1&\n\\mathbf{x}^T\\mathbf{a}_2&\n\\cdots&\n\\mathbf{x}^T\\mathbf{a}_N\n\\end{bmatrix}."} />
{/* formula: MAI2-020 */}
<Math formulaId="MAI2-020" display tex={"\\mathbf{y}^T=\\mathbf{x}^T A\n=\nx_1\\mathbf{a}_1^T+x_2\\mathbf{a}_2^T+\\cdots+x_M\\mathbf{a}_M^T."} />
### 6. Matrix–matrix multiplication

{/* formula: MAI2-021 */}
<Math formulaId="MAI2-021" display tex={"A\\in\\mathbb{R}^{M\\times N},\\quad\nB\\in\\mathbb{R}^{N\\times P},\\quad\nC=AB\\in\\mathbb{R}^{M\\times P}."} />
{/* formula: MAI2-022 */}
<Math formulaId="MAI2-022" display tex={"C_{i,j}=\\sum_{k=1}^{N}A_{i,k}B_{k,j}."} />
Collecting row–column inner products gives:

{/* formula: MAI2-023 */}
<Math formulaId="MAI2-023" display tex={"C=AB=\n\\begin{bmatrix}\n\\mathbf{a}_1^T\\mathbf{b}_1&\\mathbf{a}_1^T\\mathbf{b}_2&\\cdots&\\mathbf{a}_1^T\\mathbf{b}_P\\\\\n\\mathbf{a}_2^T\\mathbf{b}_1&\\mathbf{a}_2^T\\mathbf{b}_2&\\cdots&\\mathbf{a}_2^T\\mathbf{b}_P\\\\\n\\vdots&\\vdots&\\ddots&\\vdots\\\\\n\\mathbf{a}_M^T\\mathbf{b}_1&\\mathbf{a}_M^T\\mathbf{b}_2&\\cdots&\\mathbf{a}_M^T\\mathbf{b}_P\n\\end{bmatrix}."} />
The column–row view expresses it as a sum of outer products.

{/* formula: MAI2-024 */}
<Math formulaId="MAI2-024" display tex={"C=AB=\\sum_{i=1}^{N}\\mathbf{a}_i\\mathbf{b}_i^T."} />
Viewing B by columns, each column of C is A multiplied by one column of B.

{/* formula: MAI2-025 */}
<Math formulaId="MAI2-025" display tex={"C=A\\begin{bmatrix}\\mathbf{b}_1&\\mathbf{b}_2&\\cdots&\\mathbf{b}_P\\end{bmatrix}\n=\n\\begin{bmatrix}A\\mathbf{b}_1&A\\mathbf{b}_2&\\cdots&A\\mathbf{b}_P\\end{bmatrix}."} />
{/* formula: MAI2-026 */}
<Math formulaId="MAI2-026" display tex={"\\mathbf{c}_i=A\\mathbf{b}_i."} />
Viewing A by rows, each row of C is obtained as follows.

{/* formula: MAI2-027 */}
<Math formulaId="MAI2-027" display tex={"C=\n\\begin{bmatrix}\n\\mathbf{a}_1^TB\\\\\n\\mathbf{a}_2^TB\\\\\n\\vdots\\\\\n\\mathbf{a}_M^TB\n\\end{bmatrix}."} />
{/* formula: MAI2-028 */}
<Math formulaId="MAI2-028" display tex={"\\mathbf{c}_i^T=\\mathbf{a}_i^TB."} />
#### 6.1 Basic multiplication properties

{/* formula: MAI2-029 */}
<Math formulaId="MAI2-029" display tex={"(AB)C=A(BC)."} />
{/* formula: MAI2-030 */}
<Math formulaId="MAI2-030" display tex={"A(B+C)=AB+AC."} />
{/* formula: MAI2-031 */}
<Math formulaId="MAI2-031" display tex={"AB\\neq BA\\quad\\text{in general}."} />

{/* formula: MAI2-032 */}
<Math formulaId="MAI2-032" display tex={"I_{i,j}=\n\\begin{cases}\n1,&i=j,\\\\\n0,&i\\neq j.\n\\end{cases}"} />

As of the source's August 2026 update, PyTorch 2.13's `torch.linalg` directly provides nearly all operations covered here, including norms, determinants, rank, solve, QR, and Cholesky.

In practice, **solving the linear system `Ax=b` with `torch.linalg.solve` is often numerically and computationally preferable** to explicitly forming `A^{-1}b`.

### 10. Perspectives to remember

Rather than memorize multiplication as one formula, learn all four views.

1. Row–column inner products
2. A sum of outer products
3. Applying A to each column of B
4. Applying B to each row of A

These perspectives recur in fully connected layers, convolution's im2col representation, and attention projections.

### 1. Symmetric and skew-symmetric matrices

{/* formula: MAI3-001 */}

{/* formula: MAI3-002 */}

<Math formulaId="MAI3-004" display tex={"\\operatorname{tr}(A)=\\sum_{i=1}^{N}A_{i,i}."} />

{/* formula: MAI3-007 */}
<Math formulaId="MAI3-007" display tex={"\\operatorname{tr}(tA)=t\\,\\operatorname{tr}(A)."} />
{/* formula: MAI3-008 */}

{/* formula: MAI3-009 */}

### 3. Norms

#### 3.1 Euclidean norm

{/* formula: MAI3-010 */}
<Math formulaId="MAI3-010" display tex={"\\|\\mathbf{x}\\|_2=\\sqrt{\\sum_{i=1}^{N}x_i^2}."} />
{/* formula: MAI3-011 */}
<Math formulaId="MAI3-011" display tex={"\\|\\mathbf{x}\\|_2^2=\\mathbf{x}^T\\mathbf{x}."} />
A norm generalizes length and satisfies four properties.

{/* formula: MAI3-012 */}
<Math formulaId="MAI3-012" display tex={"f(\\mathbf{x})\\ge 0."} />
{/* formula: MAI3-013 */}
<Math formulaId="MAI3-013" display tex={"f(\\mathbf{x})=0\\iff \\mathbf{x}=0."} />
{/* formula: MAI3-014 */}
<Math formulaId="MAI3-014" display tex={"f(t\\mathbf{x})=|t|f(\\mathbf{x})."} />
{/* formula: MAI3-015 */}
<Math formulaId="MAI3-015" display tex={"f(\\mathbf{x}+\\mathbf{y})\\le f(\\mathbf{x})+f(\\mathbf{y})."} />
Other representative norms are included too.

{/* formula: MAI3-016 */}
<Math formulaId="MAI3-016" display tex={"\\|\\mathbf{x}\\|_1=\\sum_{i=1}^{N}|x_i|."} />
{/* formula: MAI3-017 */}
<Math formulaId="MAI3-017" display tex={"\\|\\mathbf{x}\\|_\\infty=\\max_i |x_i|."} />
{/* formula: MAI3-018 */}
<Math formulaId="MAI3-018" display tex={"\\|\\mathbf{x}\\|_p=\n\\left(\\sum_{i=1}^{N}|x_i|^p\\right)^{1/p},\\qquad p\\ge1."} />
For matrices, the Frobenius norm frequently appears.

{/* formula: MAI3-019 */}
<Math formulaId="MAI3-019" display tex={"\\|A\\|_F=\n\\sqrt{\\sum_{i=1}^{M}\\sum_{j=1}^{N}A_{i,j}^2}\n=\n\\sqrt{\\operatorname{tr}(A^TA)}."} />
### 4. Linear independence and rank

If one vector can be expressed as a linear combination of the others, the set is linearly dependent.

{/* formula: MAI3-020 */}
<Math formulaId="MAI3-020" display tex={"\\mathbf{x}_N=\\sum_{i=1}^{N-1}\\alpha_i\\mathbf{x}_i."} />
The lecture gives these three example vectors.

{/* formula: MAI3-021 */}
<Math formulaId="MAI3-021" display tex={"\\mathbf{x}_1=\n\\begin{bmatrix}1\\\\2\\\\3\\end{bmatrix},\\quad\n\\mathbf{x}_2=\n\\begin{bmatrix}4\\\\1\\\\5\\end{bmatrix},\\quad\n\\mathbf{x}_3=\n\\begin{bmatrix}2\\\\-3\\\\-1\\end{bmatrix}."} />
{/* formula: MAI3-022 */}
<Math formulaId="MAI3-022" display tex={"\\mathbf{x}_3=-2\\mathbf{x}_1+\\mathbf{x}_2."} />
Basic rank properties follow.

{/* formula: MAI3-023 */}
<Math formulaId="MAI3-023" display tex={"\\operatorname{rank}(A)\\le\\min(M,N),\\qquad A\\in\\mathbb{R}^{M\\times N}."} />
{/* formula: MAI3-024 */}
<Math formulaId="MAI3-024" display tex={"\\operatorname{rank}(A)=\\operatorname{rank}(A^T)."} />
{/* formula: MAI3-025 */}
<Math formulaId="MAI3-025" display tex={"\\operatorname{rank}(AB)\\le\\min(\\operatorname{rank}(A),\\operatorname{rank}(B))."} />
{/* formula: MAI3-026 */}
<Math formulaId="MAI3-026" display tex={"\\operatorname{rank}(A+B)\\le\\operatorname{rank}(A)+\\operatorname{rank}(B)."} />
### 5. Matrix inverse

{/* formula: MAI3-027 */}
<Math formulaId="MAI3-027" display tex={"A^{-1}A=I=AA^{-1}."} />
Even a square matrix has no inverse if singular. For nonsingular matrices, the following properties hold.

{/* formula: MAI3-028 */}
<Math formulaId="MAI3-028" display tex={"(A^{-1})^{-1}=A."} />
{/* formula: MAI3-029 */}
<Math formulaId="MAI3-029" display tex={"(AB)^{-1}=B^{-1}A^{-1}."} />
{/* formula: MAI3-030 */}
<Math formulaId="MAI3-030" display tex={"(A^{-1})^T=(A^T)^{-1}\\equiv A^{-T}."} />
### 6. Orthogonality and orthogonal matrices

{/* formula: MAI3-031 */}
<Math formulaId="MAI3-031" display tex={"\\mathbf{x}^T\\mathbf{y}=0."} />
{/* formula: MAI3-032 */}
<Math formulaId="MAI3-032" display tex={"\\|\\mathbf{x}\\|_2=1."} />
A square orthogonal matrix U has orthonormal columns and satisfies:

{/* formula: MAI3-033 */}
<Math formulaId="MAI3-033" display tex={"U^TU=I=UU^T."} />
If only a rectangular matrix's columns are orthonormal, just one multiplication order yields an identity.

{/* formula: MAI3-034 */}
<Math formulaId="MAI3-034" display tex={"U^TU=I,\\qquad UU^T\\neq I\\quad (U\\in\\mathbb{R}^{M\\times N},\\,N<M)."} />
Orthogonal transformations preserve Euclidean length.

{/* formula: MAI3-035 */}
<Math formulaId="MAI3-035" display tex={"\\|U\\mathbf{x}\\|_2=\\|\\mathbf{x}\\|_2."} />
### 7. Determinant

The determinant's absolute value represents the volume of the parallelotope formed by the row vectors.

{/* formula: MAI3-036 */}
<Math formulaId="MAI3-036" display tex={"S=\n\\left\\{\n\\mathbf{v}\\in\\mathbb{R}^N:\n\\mathbf{v}=\\sum_{i=1}^{N}\\alpha_i\\mathbf{a}_i,\\quad\n0\\le\\alpha_i\\le1\n\\right\\}."} />
The lecture's 2×2 example follows.

{/* formula: MAI3-037 */}
<Math formulaId="MAI3-037" display tex={"A=\n\\begin{bmatrix}\n1&3\\\\\n3&2\n\\end{bmatrix}."} />

### 8. Numerical computation in 2026

An important practical refinement is to **distinguish mathematical definitions from numerical code**.

- Inverses matter mathematically, but explicitly forming `inv(A) @ b` every time is not a good default computational habit. For linear systems, `solve` is more direct.
- Small determinants can underflow and large ones overflow, making the log determinant `slogdet` useful.
- Treat rank as **numerical rank** depending on floating-point tolerance, rather than exact symbolic rank.

Current PyTorch's `torch.linalg` includes `solve`, `slogdet`, `matrix_rank`, `qr`, `svd`, and `eigh`.

### 2. Positive definiteness and semidefiniteness

{/* formula: MAI4-003 */}

<Math formulaId="MAI4-013" display tex={"D=\\operatorname{diag}(d_1,\\ldots,d_N)\n\\quad\\Longrightarrow\\quad\n\\lambda_i=d_i."} />

### 4. Eigendecomposition of symmetric matrices

A symmetric matrix has real eigenvalues and can have orthonormal eigenvectors.

{/* formula: MAI4-017 */}
<Math formulaId="MAI4-017" display tex={"A=U\\Lambda U^T."} />

{/* formula: MAI4-018 */}

{/* formula: MAI4-019 */}
<Math formulaId="MAI4-019" display tex={"\\mathbf{y}=U^T\\mathbf{x}."} />
### 5. Gradients with respect to matrices

For a scalar-valued function of a matrix, the gradient is a matrix of partial derivatives matching the input's shape.

{/* formula: MAI4-020 */}
<Math formulaId="MAI4-020" display tex={"\\nabla_A f(A)\\in\\mathbb{R}^{M\\times N},\\qquad\n\\left(\\nabla_A f(A)\\right)_{i,j}\n=\n\\frac{\\partial f(A)}{\\partial A_{i,j}}."} />
For vector inputs, this becomes the familiar gradient.

{/* formula: MAI4-021 */}
<Math formulaId="MAI4-021" display tex={"\\nabla_{\\mathbf{x}}f(\\mathbf{x})\n=\n\\begin{bmatrix}\n\\frac{\\partial f}{\\partial x_1}\\\\\n\\frac{\\partial f}{\\partial x_2}\\\\\n\\vdots\\\\\n\\frac{\\partial f}{\\partial x_N}\n\\end{bmatrix}."} />
Linearity is preserved as well.

{/* formula: MAI4-022 */}
<Math formulaId="MAI4-022" display tex={"\\nabla_{\\mathbf{x}}\\big(f(\\mathbf{x})+g(\\mathbf{x})\\big)\n=\n\\nabla_{\\mathbf{x}}f(\\mathbf{x})+\\nabla_{\\mathbf{x}}g(\\mathbf{x})."} />
{/* formula: MAI4-023 */}
<Math formulaId="MAI4-023" display tex={"\\nabla_{\\mathbf{x}}\\big(tf(\\mathbf{x})\\big)\n=\nt\\nabla_{\\mathbf{x}}f(\\mathbf{x})."} />
### 6. Hessian

{/* formula: MAI4-024 */}
<Math formulaId="MAI4-024" display tex={"\\nabla_{\\mathbf{x}}^2 f(\\mathbf{x})\\in\\mathbb{R}^{N\\times N},\\qquad\n\\left(\\nabla_{\\mathbf{x}}^2 f(\\mathbf{x})\\right)_{i,j}\n=\n\\frac{\\partial^2 f(\\mathbf{x})}{\\partial x_i\\partial x_j}."} />
For sufficiently smooth functions, mixed partial derivatives agree and the Hessian is symmetric.

{/* formula: MAI4-025 */}
<Math formulaId="MAI4-025" display tex={"\\frac{\\partial^2f(\\mathbf{x})}{\\partial x_i\\partial x_j}\n=\n\\frac{\\partial^2f(\\mathbf{x})}{\\partial x_j\\partial x_i}."} />
### 7. Derivative formulas for linear and quadratic functions

{/* formula: MAI4-026 */}
<Math formulaId="MAI4-026" display tex={"\\nabla_{\\mathbf{x}}\\mathbf{b}^T\\mathbf{x}=\\mathbf{b}."} />
{/* formula: MAI4-027 */}
<Math formulaId="MAI4-027" display tex={"\\nabla_{\\mathbf{x}}\\mathbf{x}^TA\\mathbf{x}=2A\\mathbf{x}\n\\qquad(A=A^T)."} />

<Math formulaId="MAI4-028" display tex={"\\nabla_{\\mathbf{x}}^2\\mathbf{x}^TA\\mathbf{x}=2A\n\\qquad(A=A^T)."} />
### 8. Automatic differentiation in 2026

PyTorch can calculate these gradients, Jacobians, and Hessians without manual expansion. Autodifferentiation does not eliminate mathematics: without understanding **shape, symmetry, positive definiteness, and conditioning**, results are easy to misinterpret.

As of the source's August 2026 update, PyTorch 2.13's `torch.func` directly provides:

- `grad`
- `vjp`, `jvp`
- `jacrev`, `jacfwd`
- `hessian`
- `vmap`

Hessians involve second derivatives, so memory and compute can grow rapidly. Large-scale models often use Hessian–vector products rather than a full Hessian.

## Part 1.7: Losses, Gradient Descent, Minibatches, and Generalization

### 1. Minimize expected loss

In statistical machine learning, model D maps input x to prediction D(x), and a loss measures its discrepancy from target y.

Versions of the lecture number this equation `(4)` or `(5)`. This series **tracks the equation itself**, rather than relying on numbering alone.

{/* formula: MAI8-001 */}
<Math formulaId="MAI8-001" display tex={"\\underset{D}{\\operatorname{argmin}}\\;\nE_{\\mathbf{x},\\mathbf{y}}\n\\mathcal{L}(D(\\mathbf{x}),\\mathbf{y})."} />
### 2. Approximate expectations with finite-sample averages

The true joint data distribution is usually unknown. Training samples `(\mathbf{x}_l,\mathbf{y}_l)` approximate expected loss through an empirical average.

{/* formula: MAI8-002 */}
<Math formulaId="MAI8-002" display tex={"E_{\\mathbf{x},\\mathbf{y}}\n\\mathcal{L}(D(\\mathbf{x}),\\mathbf{y})\n\\approx\n\\frac1L\\sum_{l=1}^{L}\n\\mathcal{L}(D(\\mathbf{x}_l),\\mathbf{y}_l)."} />
The March 19, 2025 version presents the right side as `??` for students to complete. The expression above is completed using the earlier version and surrounding context.

### 3. MSE example

{/* formula: MAI8-003 */}
<Math formulaId="MAI8-003" display tex={"\\underset{D}{\\operatorname{argmin}}\\;\nE_{\\mathbf{x},\\mathbf{y}}\n\\mathcal{L}(D(\\mathbf{x}),\\mathbf{y}),\n\\qquad\n\\mathcal{L}(D(\\mathbf{x}),\\mathbf{y})\n=\n\\|D(\\mathbf{x})-\\mathbf{y}\\|_2^2."} />
{/* formula: MAI8-004 */}

### 4. Gradient

The gradient of `f:\mathbb{R}^N\to\mathbb{R}` points toward steepest increase and is perpendicular to level curves.

{/* formula: MAI8-005 */}
<Math formulaId="MAI8-005" display tex={"\\nabla f(\\mathbf{z})\n=\n\\begin{bmatrix}\n\\frac{\\partial f}{\\partial x_1}(\\mathbf{z})&\n\\cdots&\n\\frac{\\partial f}{\\partial x_N}(\\mathbf{z})\n\\end{bmatrix}^{T}."} />
### 5. Conditions for a local minimum

{/* formula: MAI8-006 */}
<Math formulaId="MAI8-006" display tex={"\\nabla f(\\mathbf{x}^*)=0."} />
{/* formula: MAI8-007 */}
<Math formulaId="MAI8-007" display tex={"\\mathbf{y}^T\\nabla^2f(\\mathbf{x}^*)\\mathbf{y}>0,\n\\qquad\n\\forall\\mathbf{y}\\neq0,\\ \n\\mathbf{y}\\in\\mathbb{R}^{N}."} />
{/* formula: MAI8-008 */}
<Math formulaId="MAI8-008" display tex={"\\left[\\nabla^2f(\\mathbf{x})\\right]_{m,n}\n=\n\\frac{\\partial^2f}{\\partial x_m\\partial x_n}(\\mathbf{x})."} />
### 6. Gradient descent

{/* formula: MAI8-009 */}
<Math formulaId="MAI8-009" display tex={"\\mathbf{x}^{(i+1)}\n=\n\\mathbf{x}^{(i)}\n-\n\\alpha\\nabla f(\\mathbf{x}^{(i)})."} />
A learning rate `\alpha` that is too small slows convergence; one that is too large can cause divergence.

Computing each gradient from the full dataset is expensive for large L. The MSE example requires the following gradient across every sample.

{/* formula: MAI8-010 */}
<Math formulaId="MAI8-010" display tex={"\\nabla_D\n\\left\\|\nD(\\mathbf{x}_l)-\\mathbf{y}_l\n\\right\\|_2^2,\n\\qquad\nl=1,\\ldots,L."} />
### 7. Stochastic minibatch gradient descent

First shuffle sample indices randomly and divide them into batches of size B.

{/* formula: MAI8-011 */}
<Math formulaId="MAI8-011" display tex={"\\{1,\\ldots,L\\}\n=\n\\mathcal{L}^{(1)}\n\\cup\\cdots\\cup\n\\mathcal{L}^{(L/B)},\n\\qquad\n|\\mathcal{L}^{(i)}|=B."} />
Update for each batch as follows.

{/* formula: MAI8-012 */}
<Math formulaId="MAI8-012" display tex={"\\mathbf{x}^{(i+1)}\n\\leftarrow\n\\mathbf{x}^{(i)}\n-\n\\alpha\n\\sum_{l\\in\\mathcal{L}^{(i+1)}}\n\\nabla f_l(\\mathbf{x}^{(i)})."} />
The lecture defines total empirical loss by this sum.

{/* formula: MAI8-013 */}
<Math formulaId="MAI8-013" display tex={"\\sum_{l=1}^{L}f_l(\\mathbf{x})."} />
### 8. The batch-size debate

The lecture introduces Keskar and colleagues' ICLR 2017 findings: an empirical observation that large batches can approach sharper minimizers and generalize worse.

However, **“sharp minima always generalize poorly” is not a theorem**. A 2017 response already showed reparameterizations changing sharpness without changing the function, and 2025 research also reported sharp minima that generalize well.

A more careful 2026 reading is:

- Evaluate batch size together with gradient noise, throughput, memory, and learning-rate schedules.
- Sharpness is one useful diagnostic but can depend on parameterization.
- Large-scale training jointly optimizes hardware utilization and optimization stability, rather than assuming smaller batches are always better.
