> 검토 범위: *Nature Medicine* Article in Press 공식 본문·초록·Source Data·Supplementary 목록, 공개 preprint 전문, 공개 코드 설계 문서. 최종 조판 PDF의 페이지·Figure 번호는 접근하지 못했으므로 확인했다고 쓰지 않는다. 2026년 3월 preprint가 11월 16일 동료평가 논문으로 승인·공개된 후속 트리거다.

## 1. 한 문장 결론

OpenScientist는 생의학 데이터 분석을 빠르게 반복하고 검증 가능한 가설을 만드는 공개형 AI 공동과학자지만, 무작위 대조에서도 일부 가설을 완전히 기각하지 못했기 때문에 독립 과학자가 아니라 전문가가 감독하는 분석 가속기로 봐야 한다.

## 2. 왜 어려운가

생의학 연구는 논문 검색, 데이터 정리, 통계 분석, 가설 갱신, 결과 해석을 여러 번 오간다. 각 단계는 다른 전문지식을 요구하고, 작은 전처리 오류가 마지막 결론까지 전파될 수 있다. 일반 챗봇은 답을 한 번 생성하지만, 과학 분석은 코드·데이터·문헌·음성적 가설을 반복해서 대조해야 한다. 특히 환자 데이터에서는 개인정보와 분석 재현성도 동시에 지켜야 한다.

## 3. 기초 개념

Agentic AI는 목표만 받은 뒤 필요한 하위 과제를 정하고 도구를 실행하며 중간 상태를 갱신하는 시스템이다. OpenScientist의 핵심 기록은 knowledge state다. 각 반복에서 확인한 결과, 분석 코드, 문헌 근거, 남은 가설을 구조화해 다음 반복에 넘긴다. coinvestigate mode에서는 연구자가 반복 사이에 방향을 수정할 수 있다.

## 4. 기존 방식의 한계

기존 AI co-scientist의 상당수는 내부 모델·프롬프트·실행 로그가 공개되지 않거나, 문헌 질의와 아이디어 생성에 집중한다. 결과가 좋아 보여도 어떤 데이터 변환과 통계 선택으로 나왔는지 재현하기 어렵다. 반대로 고정된 bioinformatics workflow는 재현성은 높지만 질문이 바뀔 때 새로운 분석을 조합하기 어렵다.

## 5. 새 방법의 세 단계

첫째, 연구자가 질문과 선택적 데이터 파일을 입력한다. 시스템은 데이터 구조를 확인하고 PubMed 문헌을 찾아 가능한 기전을 만든다.

둘째, 코드 작성 에이전트가 여러 iteration 동안 분석 코드를 실행하고 가설을 검정한다. 결과와 provenance를 knowledge state에 저장하며, 비용·작업 상태도 추적한다.

셋째, 누적된 결과로 보고서를 만들고 전문가·외부 cohort·hidden evaluation·무작위 negative control과 비교한다. 민감한 임상 데이터는 runtime과 기반 모델을 같은 보안 환경에 두는 경우 air-gapped 운용이 가능하다고 저자들은 보고한다.

## 6. 핵심 시스템 경계

이 논문의 핵심은 새로운 단일 수식보다 분석 경계다.

`질문·데이터 → 문헌 검색과 코드 실행 → 반복 가설 검정 → knowledge state → 최종 보고서 → 전문가·외부 데이터 검증`

입력에는 임상·오믹스 데이터와 자연어 질문이 들어간다. 출력은 분석 코드, 통계 결과, 문헌 근거, 가설과 보고서다. 모델 API를 외부에서 호출하면 air gap이 아니다. 또한 시스템이 임의 코드를 실행하므로 격리와 권한 제한이 안전 경계에 포함된다.

## 7. 실험과 수치

동료평가 논문은 다섯 생의학 사례를 제시한다. Alzheimer 혈액 biomarker, plasma proteomic survival model, tau pathology와 lysosomal acidification 기전, multiple myeloma 외부 cohort 검증, 사람 분석과의 blinded·prespecified proteomic 비교다. Source Data에는 개발기간 93회 실행의 배정과 ROC·AUC·95% CI, survival model c-index가 공개됐다.

공개 preprint의 개발 흐름에서는 93회 중 user error 2회와 기술 실패 3회가 있었다. 남은 88회 중 22회는 문헌 검색만 수행했고, 66회 분석 실행은 29개 주제로 나뉘었다. tau 사례의 주장된 log2 fold change와 전문가 재계산의 상관은 r=0.983이었다. 그러나 8명 donor의 세포가 반복 측정된 계층구조를 주 분석이 충분히 모델링하지 못했다. 일반적인 실행 비용은 10달러 미만으로 보고됐지만, 이는 데이터 준비와 전문가 검수 비용을 포함한 전체 연구비가 아니다.

## 8. 반대 증거

가장 중요한 반대 증거는 randomized control이다. OpenScientist는 무작위화 데이터의 signal-to-noise ratio가 검증 데이터보다 6.9배 낮다고 감지했지만, 진짜 생물학적 구조를 제거한 뒤에도 일부 가설이 통계적으로 지지됐다. 초기 SEABIRD 반복에서는 빈 셀을 0으로 처리해 PET 데이터가 없는 참가자를 음성으로 분류했고, 표본 수·confidence interval·통계 방법을 일관되게 보고하지 못했다. 분석 결과가 그럴듯하다는 사실과 가설이 참이라는 사실은 다르다.

## 9. 한계

최종 보고서는 원자료를 직접 다시 읽기보다 iteration 요약을 거쳐 만들어져 요약 오류가 누적될 수 있다. 여러 반복에 걸친 multiple-testing correction이 충분하지 않았고, 일부 domain skill은 metabolite ratio를 flux처럼 해석하거나 RNA-seq count에 부적절한 통계를 적용했다. 기존 데이터의 후향 분석이므로 새로운 임상 효용을 입증하지 않는다. 최종 조판 PDF와 최종판의 Figure 페이지는 미확인이다.

## 10. 실제로 무엇이 바뀌나

연구자는 문헌 검색과 반복 분석의 첫 초안을 빠르게 만들 수 있다. 그러나 배포 기준은 ‘좋은 보고서를 생성했는가’가 아니라 데이터 누출 방지, 모든 분석 로그 보존, 사전 지정·사후 분석 구분, 전체 가설 수에 대한 오류율 통제, negative control 통과, 외부 cohort 재현이다. 사람의 책임을 AI에 넘기는 도구가 아니라 검토 가능한 분석 후보를 더 빨리 만드는 도구다.

## 11. 다음 확인 트리거

최종 Version of Record, 독립 기관의 동일 데이터 재현, prospectively registered study, wet-lab 또는 임상 후속 검증, 무작위·adversarial control에서 완전한 가설 기각, 전체 provenance를 사용한 보고서 생성, air-gapped 환경의 보안 평가가 확인되면 `RESEARCH_READY`를 재검토한다. 현재는 `SOURCE_REVIEWED`와 `NOT_ENOUGH_DEPTH`를 함께 유지한다.
