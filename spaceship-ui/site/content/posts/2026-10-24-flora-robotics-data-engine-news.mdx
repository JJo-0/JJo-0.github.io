> **BACKLOG_CANDIDATE** — 기준일 2026-10-24 KST · rank 3 · 90/100 · EARLY_SIGNAL · 검토 범위: NVIDIA 공식 기술보고서, 프로젝트 페이지, 공개 모델 카드. 동료평가 논문이 아니며 독립 재현은 하지 않았다.

## 한 문장 결론

Flora는 로봇 영상을 시간 구간별 설명과 성공·실패 보상으로 바꾸는 세 공개 모델을 묶어 대규모 데이터 엔진으로 제시했지만, 최고 처리량은 자체 인프라 수치이고 API 비교는 실측이 아니라 모델링이다.

## 중요성과 차이

로봇 학습의 병목은 영상이 없어서가 아니라 “언제 어떤 행동을 했고 얼마나 잘했는지”를 일관되게 붙이는 비용이다. Flora는 TempSeg 9B가 사건 경계를 찾고, Captioner 27B가 구간을 설명하며, Rewarder 28B가 전체 결과·과정·사용자 rubric 보상을 낸다. 하나의 거대 모델 호출 대신 구간 분할과 설명을 분리해 긴 영상의 문맥 비용을 줄인 점이 기존 API 라벨링과 다르다.

## 수치와 비교조건

기술보고서는 512개 GB300 GPU에서 하루 최대 200,000시간의 영상을 라벨링했다고 보고한다. WGO-Bench 평균에서 Flora의 segmentation F1@0.75는 50.3, gold-window caption accuracy는 64.7%, joint semantic F1@0.75는 34.5%였다. Refiner 대비 평균 segmentation F1은 16.9점, joint F1은 7.3점 높았고 gold-window caption은 64.7% 대 64.3%로 비슷했다. 서로 다른 API 모델의 연산량·backend는 공개되지 않아 compute-matched 비교가 아니다.

## 한계·반대 증거

처리량 그래프의 외부 API 지점은 quota와 토큰 수로 계산한 조건부 상한이며 실제 wall-clock 측정이 아니다. 비용점도 동일 예산으로 맞추지 않았다. DenseRewardBench에서 Flora-Rewarder는 정상 step의 약 11%를 실패로 표시했다. 완전 실패·완전 성공 사례에서는 GPT-6 Astra가 적어도 동등하게 정확했고, Flora의 장점은 부분 완료 상태에 집중됐다. 데이터셋과 judge 설계가 자체 모델에 유리할 가능성도 남는다.

## code/data·이해관계

Captioner·TempSeg·Rewarder 가중치와 프로젝트 자료가 Hugging Face에 공개됐다. 다만 NVIDIA Open Model License의 비상업 조건이 적용되며, 학습 데이터 전체와 512-GPU 운영 스택의 완전한 재현 가능성은 확인하지 못했다. 저자 전원이 NVIDIA 및 협력 연구진이고 평가·모델·인프라를 같은 조직이 제공한다.
