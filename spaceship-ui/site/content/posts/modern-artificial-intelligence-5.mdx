### 5.2 AlexNet — Overview / Details.

{/* source-content:P5-C016 */}

AlexNet을 ILSVRC 2012 winner로 소개하고 당시 약 60M parameters, 650K neurons의 큰 CNN이었다고 설명한다.

{/* source-content:P5-C017 */}

입력 이미지를 1,000 classes 중 하나로 분류하고, 1,000-dimensional output의 각 성분을 class probability로 해석하며 전체 합을 1로 둔다.

{/* source-content:P5-C018 */}

입력은 RGB 256x256으로 맞추며, 작은 쪽을 256으로 resize 후 crop한다. grayscale이면 single channel을 복제해 RGB 3-channel로 만든다.

{/* source-content:P5-C019 */}

학습 시 256x256 내부에서 227x227 random crop을 생성해 첫 layer에 넣는다.

{/* source-content:P5-C020 */}

AlexNet은 5 convolutional layers + 3 fully-connected layers로 구성된다.

<Part5ArchitectureVisual kind="alexnet" />

{/* source-content:P5-C021 */}

conv/FC 뒤에는 ReLU를 사용하고 초기 두 convolution 뒤에는 local normalization 후 pooling을 적용한다. 슬라이드는 이후 normalization이 큰 효용을 보이지 않았다고 덧붙인다.

{/* source-content:P5-C022 */}

ReLU가 tanh/sigmoid 같은 saturating activation보다 deep CNN 학습을 빠르게 했다는 점을 핵심으로 제시한다.

## PDF p.5 — AlexNet: ReLU·augmentation·dropout

{/* source-content:P5-C023 */}

**그림 원자료.** CIFAR-10 실험 도표에서 ReLU(solid)가 tanh(dotted)보다 25% training error에 약 6배 빠르게 도달했다고 설명한다.

{/* source-content:P5-C024 */}

tanh는 큰 양/음 입력에서 saturate해 slope가 0에 가까워지고 gradient descent를 느리게 할 수 있다고 설명한다.

{/* source-content:P5-C025 */}

ReLU는 positive 영역에서 slope가 0에 가깝지 않아 optimization이 빠르다는 직관을 제시한다. negative 영역 slope는 0이라는 점도 함께 적는다.

{/* source-content:P5-C026 */}

overfitting 완화를 위해 mirroring과 random crops를 사용한다. mirroring은 dataset을 2배, random cropping은 자료 표현상 2048배로 늘린다고 적는다.

{/* source-content:P5-C027 */}

또 다른 regularization으로 dropout을 사용한다.

{/* source-content:P5-C028 */}

**그림 원자료.** 하단은 AlexNet의 intermediate feature maps 예시를 보여준다.

## PDF p.6 — 5.3 VGGNet: 작은 kernel을 깊게 쌓기

### 5.3 VGGNet — Overview / Motivation / Details.

{/* source-content:P5-C030 */}

VGG16은 16-layer CNN이며 ILSVRC-2014 상위 모델로 소개되고 ImageNet test accuracy 92.7%라고 적는다.

{/* source-content:P5-C031 */}

AlexNet의 큰 early kernels(11x11, 5x5) 대신 작은 3x3 filter sequence를 사용한다.

{/* source-content:P5-C032 */}

첫 convolution에서 3x3 receptive field, stride 1을 사용하며 AlexNet의 11x11 stride 4와 비교한다.

{/* source-content:P5-C033 */}

여러 작은 convolution을 쌓으면 더 많은 nonlinear activation을 삽입하면서 큰 receptive field의 기능을 얻는다는 motivation을 제시한다.

{/* source-content:P5-C034 */}

슬라이드는 작은 convolution이 over-fitting 경향을 낮추고 3x3이 spatial left-right/up-down 정보를 잡는 최소 크기라는 식의 설명을 제시한다.

{/* source-content:P5-C035 */}

VGG16은 약 138M parameters이며, 13 convolutional + 3 FC layers로 설명한다.

## PDF p.7 — VGG16 세부와 GoogLeNet 진입

{/* source-content:P5-C036 */}

VGG input은 RGB 224x224이며 ImageNet에서는 center crop으로 크기를 일정하게 맞춘다고 적는다.

{/* source-content:P5-C037 */}

convolution은 주로 3x3을 쓰고 1x1 convolution도 사용한다. 1x1은 receptive field를 바꾸지 않으면서 ReLU와 함께 non-linearity를 늘리는 용도로 설명한다.

{/* source-content:P5-C038 */}

hidden layers는 ReLU를 쓰며 AlexNet식 Local Response Normalization은 시간/메모리를 늘리고 accuracy 개선이 작다고 설명한다.

{/* source-content:P5-C039 */}

pooling은 feature-map dimensionality와 parameter burden을 줄이며 channel 수는 64→128→256→512로 늘어난다.

{/* source-content:P5-C040 */}

FC layers는 4096, 4096, 1000 channels이다.

{/* source-content:P5-C041 */}

두 개의 3x3은 5x5, 세 개의 3x3은 7x7 receptive field에 대응한다고 설명한다.

{/* source-content:P5-C042 */}

세 3x3 layer는 세 번의 ReLU를 제공하고 27C^2 parameters로, 하나의 7x7의 49C^2보다 적은 parameter를 사용한다.

{/* source-content:P5-C043 */}

## PDF p.12 — ResNet 세부·BN·5.6 WRN

{/* source-content:P5-C074 */}

ResNet에서는 34-layer가 18-layer보다 좋은 결과를 보이고 training error도 낮아 plain-net degradation이 해결됨을 설명한다.

{/* source-content:P5-C075 */}

### Further details.

{/* source-content:P5-C076 */}

ResNet은 every convolutional layer 뒤에 batch normalization을 사용한다고 설명한다.

{/* source-content:P5-C077 */}

BN은 current batch mean/variance로 hidden activation을 normalize하며 일반적으로 nonlinear function 직전에 적용한다고 설명한다.

{/* source-content:P5-C078 */}

BN의 효과에 대한 해석은 확정되지 않았다고 적고, original internal covariate shift 설명, layer interdependency 완화 가설, optimization landscape smoothing 설명을 병렬로 소개한다.

{/* source-content:P5-C079 */}

ResNet에는 dropout을 쓰지 않는다고 적는다.

{/* source-content:P5-C080 */}

### 5.6 Wide residual network (WRN).

{/* source-content:P5-C081 */}

ResNet을 widen하면 같은/더 좋은 accuracy에서 shallower network를 만들 수 있어 layer 수와 training time을 줄일 수 있다고 설명한다.

{/* source-content:P5-C082 */}

circuit complexity 관점에서 shallow circuits가 deeper circuits보다 exponentially more components를 요구할 수 있음을 언급한다.

{/* source-content:P5-C083 */}

thin/deep ResNet에서 gradient가 residual weights를 우회해 일부 block만 유용한 representation을 학습할 수 있는 diminishing feature reuse 문제를 설명한다.

{/* source-content:P5-C084 */}

WRN은 feature planes를 늘려 widen하고, deepening factor l과 widening factor k를 사용한다. k=1은 ResNet width, k>1은 k배 wider이다.

{/* source-content:P5-C085 */}

> **원자료 각주.** BN이 nonlinear function 뒤에 적용되는 경우도 있다는 footnote를 보존한다.

## PDF p.14 — Dense block: sequential/addition/concatenation

{/* source-content:P5-C094 */}

Dense block에서 standard feed-forward network는 l-th output을 (l+1)-th input으로 연결한다.

{/* source-content:P5-C095 */}

표준 transition을 `x_l=H_l(x_{l-1})`로 정의하고 H_l을 convolution/ReLU/pooling/BN 등의 composite function으로 설명한다.

{/* source-content:P5-C096 */}

ResNet은 identity mapping과 element-wise addition을 사용해 `x_l=H_l(x_{l-1})+x_{l-1}` 형태를 만든다.

{/* source-content:P5-C097 */}

DenseNet은 모든 preceding features를 concatenation해 `x_l=H_l([x_0,...,x_{l-1}])`로 입력한다.

{/* source-content:P5-C098 */}

DenseNet의 H_l은 BN→ReLU→3x3 convolution의 연속 연산으로 정의된다.

{/* source-content:P5-C099 */}

dense blocks 사이 transition layer는 1x1 convolution 뒤 2x2 average pooling을 사용한다.

{/* source-content:P5-C100 */}

dense block 안에서는 feature-map sizes가 같아 concatenation이 가능하고 마지막 dense block 뒤에는 GAP와 softmax classifier를 붙인다.

# 편집·수학 검증

{/* editorial-content:P5-E001 */}

### P5-E001
VGG 슬라이드의 '3x3 is the optimal/smallest possible size'는 spatial context를 동시에 보는 최소 odd kernel이라는 강의 직관으로 읽어야 한다. 1x1 convolution도 존재하며, 3x3이 모든 목적에서 보편적 최적이라는 뜻으로 일반화하면 안 된다.

{/* editorial-content:P5-E002 */}

### P5-E002
AlexNet 슬라이드의 ReLU 직관 중 'most neurons usually end up positive'는 일반 정리로 취급하지 않는다. ReLU의 비포화 positive branch가 optimization에 유리했다는 역사적 설명과 해당 문장을 분리한다.

{/* editorial-content:P5-E003 */}

### P5-E003
BN 효과 설명은 원자료처럼 multiple hypotheses를 보존한다. internal covariate shift 하나로 원인을 확정하지 않고, optimization landscape 및 reparameterization 관점이 후속 연구에서 논의됐음을 명시한다.

{/* editorial-content:P5-E004 */}

### P5-E004
DenseNet의 'higher computational and memory efficiency'는 parameter reuse/compactness 맥락의 source claim이다. dense concatenation은 activation-memory traffic를 늘릴 수 있으므로 현대 구현의 hardware efficiency와 동일시하지 않는다.

{/* editorial-content:P5-E005 */}

### P5-E005
SE architecture의 ILSVRC 2017 winner 표현은 source wording을 보존하되, challenge 종료 시점과 SENet의 competition result를 역사적 맥락으로 읽는다.

## 2026 관점에서 다시 읽는 한 줄 지도

AlexNet은 **ReLU + data augmentation + dropout**으로 대규모 CNN 학습을 현실화했고, VGG는 **작은 3×3 kernel을 깊게 쌓는 단순성**, GoogLeNet은 **1×1 bottleneck + multi-branch Inception + GAP**, ResNet/WRN은 **identity path와 depth/width trade-off**, DenseNet은 **feature reuse via concatenation**, SE는 **channel-wise adaptive recalibration**을 강조했다.

2026년에는 여기에 **ViT/Swin의 attention backbone**, **ConvNeXt류의 modernized ConvNet**, **training/scaling recipe**, **self-supervised/multimodal foundation encoder**, 그리고 **calibration·distribution shift·robustness·transfer**가 함께 평가축으로 들어간다. 따라서 “어떤 architecture가 ImageNet top-1이 가장 높은가?” 하나만 묻는 방식은 더 이상 충분하지 않다.
