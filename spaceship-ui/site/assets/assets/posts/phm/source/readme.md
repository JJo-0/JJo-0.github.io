# PHM motor experiment archive

These files preserve the exploratory Python scripts used for the 2024 motor-vibration experiment. They are historical evidence, not a ready-to-run package.

- Original scripts contain machine-specific `/Volumes/...` paths.
- The private research dataset is not included in the website repository.
- `phm-reproducible.py` is a cleaned reference pipeline. Supply CSV files and adapt the schema/label parser.
- Split by physical measurement session before fitting preprocessing.

The PNG files in `../results/` are original experiment outputs. Their labels identify sensor groups, not proven fault classes.
