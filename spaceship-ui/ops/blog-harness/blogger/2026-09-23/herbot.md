# HER2 양성 담도암 4제 병용, 55% 반응률 읽는 법

![원문 Figure 1. HERBOT 참가자 흐름](/assets/posts/news-20260923/herbot-fig-1.png)

HERBOT는 사람 임상 1b/2상, 단일군 40명 연구입니다. trastuzumab·nivolumab·gemcitabine·cisplatin을 함께 썼고 22명이 객관적 반응을 보여 ORR 55%였습니다.

![원문 Figure 2. 환자별 종양 감소와 시간 변화](/assets/posts/news-20260923/herbot-fig-2.png)

55%는 기존 치료보다 55% 개선됐다는 뜻이 아닙니다. CR 1명과 PR 21명을 전체 40명으로 나눈 값이고, 95% 신뢰구간은 38.5~70.7%입니다.

![원문 Figure 3. PFS와 OS Kaplan-Meier 곡선](/assets/posts/news-20260923/herbot-fig-3.png)

median PFS는 10.6개월이었지만 무작위 대조군이 없습니다. grade 3 이상 neutropenia 57.5%도 함께 봐야 합니다. 다음 단계는 randomized phase 3입니다.
