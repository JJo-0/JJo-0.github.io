논문이 실행 가능한 AI 에이전트가 됐다

Paper2Agent는 논문에 질문하는 기능을 넘어, 논문의 방법을 실제로 호출할 수 있는 실행 인터페이스로 정리합니다. 2026년 9월 16일 Nature에 게재된 연구는 논문·코드·데이터를 MCP 도구와 자료로 구성한 뒤, 에이전트가 자연어 요청에 맞춰 이를 사용하게 하는 접근을 평가했습니다.

연구 방법을 재사용하려면 논문을 읽은 다음에도 설치 환경, 입력 형식, 실행 순서와 결과의 의미를 확인해야 합니다. 언어모델이 매번 새 분석 코드를 작성하면 이 과정도 반복해서 검토해야 합니다. Paper2Agent는 준비 단계에서 실행 함수를 만들고 기준 결과와 비교한 뒤, 통과한 도구를 다음 질문에서 재사용하도록 합니다.

위 원본 그림의 주황색은 실행 도구, 녹색은 원고와 연구 자료, 파란색은 작업 순서를 안내하는 지침입니다. 아래 흐름에서는 환경 준비와 기능 추출이 테스트로 모이고, 수정과 재시험을 거쳐 서버로 연결됩니다. 이 그림은 2025년 preprint의 개요이며, 아래 규모 평가 숫자는 2026년 Nature 정식 출판본을 기준으로 합니다.

여기서 중요한 것은 숫자마다 분모가 다르다는 점입니다. 연구팀은 computational biology 논문 100편 가운데 74편을 에이전트로 변환했습니다. 그 과정에서 제안한 도구 599개 중 593개가 자동 검증을 통과했습니다. 약 99%라는 도구 검증률은 이미 제안된 함수의 품질을, 74%라는 논문 변환률은 자동화가 도달한 전체 범위를 설명합니다.

변환에 성공한 논문에서 만든 질문 300개에서는 Paper2Agent와 Sonnet 4가 91.2±1.6%, 같은 Sonnet 4의 직접 저장소 사용은 80.3±2.3%로 보고됐습니다. 차이는 10.9퍼센트포인트입니다. 평균 질의 비용과 시간도 0.20달러·1.6분 대 0.38달러·4.3분으로 낮았습니다. 전체 도입 비용을 판단할 때에는 최초 도구 구축과 이후 유지관리 비용을 따로 더해야 합니다.

다른 분야의 10편 논문·42개 실행 과제에서는 98.1±0.8%를 보고했습니다. 또한 별도로 고른 데이터·발견 중심 논문 26편에서는 자료를 정리해 정보 종합 질문에 답하는 방식도 평가했습니다. 이 26편은 앞의 변환 실패 26편과 다른 논문 집합입니다. 두 평가를 섞으면 어떤 종류의 작업을 검증했는지 놓치게 됩니다.

검증된 실행과 과학적으로 타당한 결론도 구분해야 합니다. 원래 코드와 같은 결과를 내는 도구라도 새 데이터에 분석 전제가 맞는지까지 자동으로 보증하지는 않습니다. 저자들은 열린 분석에서 하나의 기준 답과 일치하는지보다 넓은 판단이 필요하다는 점을 설명합니다. 실패한 26편의 코드·데이터·의존성 문제 역시 연구 소프트웨어의 준비 상태를 보여 줍니다.

유전체 사례에서는 여러 논문 에이전트를 연결해 GPR137을 건선 관련 후보 유전자로 지지하는 분석을 수행했습니다. 시스템이 제시한 전략 중 사람이 상관분석을 선택했고, 기존 실험 자료를 연결해 계산했습니다. 새 생체 실험을 했다는 의미와는 구분하면서, 서로 다른 연구 자료를 재사용하는 가능성에 주목할 수 있습니다.

전체 해설에는 두 원본 그림을 따라 읽는 설명, 각 평가의 분모와 비교 조건, 누르면 펼쳐지는 세 가지 계산 해설, 향후 확인할 재현성과 운영 조건을 담았습니다.
