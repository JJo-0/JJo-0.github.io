- 녹화/표지의 강의 회차와 공식 주차는 한 회 차이가 있다. 블로그 장 번호는 공식 주차를 따른다.
- [고정 이미지 사본](https://github.com/SRA-VJTI/robotics-study-group/tree/077f2bfe53b01005e0b2e29ae43b6f0c0ba3c0a8/assets/lectures/week-10) 57개를 내려받아 OCR로 페이지 내용을 대조했다. 원본 PDF의 바이트 일치는 확인하지 않았다.
- 본문에 42개 슬라이드를 표시한다. 모든 이미지는 기존 `LectureSlide`의 고정 원격 사본을 참조하고 지연 로딩한다. 원격 사본의 저작권·각 인용 그림과 영상의 권리는 Oier Mees 및 원저작권자에게 있으며 새 라이선스를 부여하지 않는다.
- [이미지 무결성 목록](slide-manifest.json)에 각 페이지 SHA-256과 표시 여부를 기록했다. 원본 JPEG를 이 저장소에 새로 복제하지 않았다.
- 사용자 전사의 전체 문장과 기존 글을 대조했다. 공개 문서는 [대조 기록](../../reviews/2026-11-09-transcript-coverage.md)에 대응 범위와 수치 정정 이유만 남긴다. 사용자 원전사는 공개하지 않는다.
- P020–P033은 같은 학습 구조의 애니메이션이다. 본문에서는 시작·최종 상태(P020·P033)를 표시하고 중간 프레임은 원본 목록에 연결했다. P001 표지·P056 감사·P057 참고문헌은 기술 설명을 반복하지 않는다.
