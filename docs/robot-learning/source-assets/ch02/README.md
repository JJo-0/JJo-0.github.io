# 02장 원본·자막 대조 기록

날짜: 2026-11-04. 공식 2강은 Robot Control & MDPs (2026-02-23)다. [강의 홈페이지](https://cvg.ethz.ch/lectures/Robot-Learning/)에서 PDF와 영상 연결을 확인했다.

- 공식 PDF는 다운로드했으나 암호화되어 정상적인 무인증 열람이 되지 않았다. 암호 해제나 사본과의 동일성 대조를 수행하지 않았다. 재구성한 PPT를 원본이라 부르지 않는다. 편집 가능한 공식 PPTX는 이번 공식 강의 페이지에서 제공되지 않았다.
- 공개 JPEG 사본 커밋 `077f2bfe53b01005e0b2e29ae43b6f0c0ba3c0a8`의 week-02 46장을 다운로드했다. P번호는 파일 번호이며 슬라이드 인쇄 번호는 대체로 하나 작다. 공개 본문은 운영·전환·마무리 장 2·29·45·46을 제외한 42장이다.
- 전체 46장의 축소 개요를 시각 확인했다. 수식 중심 5·11·21·23·25·27·37·42·44장은 1600×900에서 추가로 확인했다. 모든 페이지의 작은 글씨까지 원해상도 정밀 검수를 했다고 기록하지 않는다.
- 영어 OCR 텍스트와 단어 위치는 이미지와 별도로 보관했다. 사진·도표 3영역과 수식/수식 포함 도표 6영역을 좌표에 따라 잘라 보관했다. 래스터 영역 분리이며 원본 벡터·편집 가능한 수식·자동으로 정확한 LaTeX를 얻었다는 뜻은 아니다. 본문은 전체 슬라이드를 유지하고 중요한 수식 14개를 재조판했다.
- ETH `5-Bb84eTTqQ`의 영어 자동 자막 1,187구간을 직접 확보했다. 기술 부분 1:00–45:57을 읽어 대응시켰다. 전체 음성 청취와 자막 텍스트 확인은 구별한다.
- Modern Robotics의 변환 `vlb3P7arbkU` 86구간, 시간 스케일링 `0ZqeBEa_MWo` 41구간 영어 자막을 확보했다. API의 is_generated=False를 확인했다. 공식 영상 부속 웹페이지의 스크립트도 함께 읽었다. UCL `TCCjZe0y4Qc`는 기존 확보본의 마르코프·부분 관측 구간을 재확인했다. 전체 자막 전문을 공개 글에 전재하지 않았다.

본문의 보완: 관절 구성과 동역학적 상태, 각도 주기성과 관절 제한, 관절 경로와 손끝 경로, 야코비안 전치법과 역행렬법, 보간 구간 수와 양 끝점 수, 제어 주기, 센서 잡음과 전이 외란, 음의 거리 보상, 확률과 연속 밀도, 시간 제한과 과업 종료, 여러 최적 정책을 구별했다.

수식 출처·기호 변경·자체 예제의 구분과 파일 해시는 [manifest.json](manifest.json)을 따른다. 2R FK, 부호·확률·PID 수치 예제는 교육용 추가다. 공식 HW2는 특정 커밋의 README와 관련 코드를 읽었고 실행하지 않았다. 실행 증거는 [별도 Gymnasium 예제](../../labs/02-control-mdp/README.md)의 고정 PD 제어와 수치 계산에 한정된다.

슬라이드의 권리는 Oier Mees 및 포함 자료별 권리자에게 있다. 출처 표기가 사용 허락 자체를 뜻하지 않는다. 다운로드 원본·텍스트·분리 영역·자막은 기존 개인 Drive의 02장 폴더에 보관하며 공개 GitHub에는 원본 전문 자막을 올리지 않는다.

## 원본·자막 재대조 및 다른 자료 통합

사용자의 보완 요청에 따라 18개 기술 구간을 다시 대조하고 원고 본문에 다른 자료의 해당 개념을 추가했다. [supplement-review.json](supplement-review.json)은 ETH 페이지·시간 자막·추가 개념의 대응표다. 6·21·28·34·37·39·43장은 1600×900 사본으로 다시 확인했다. 공식 암호화 PDF의 동일성 검증 상태는 바꾸지 않는다.

추가 자료는 Modern Robotics의 수치 IK와 중력 아래 PD/PID 강의·자막, David Silver의 공식 UCL MDP PDF와 Google DeepMind 영상 자막, 기존 UCL2021·NTU 자막, NVIDIA Isaac Lab의 특정 커밋 소스와 MuJoCo 구동기 문서다. 참고문헌뿐 아니라 해당 슬라이드 아래 설명에 개념·수식·수치 예제를 연결했다.

- 신규 원본 도식 2개: UCL의 관측 중복 미로, Silver의 학생 마르코프 연쇄. PDF 페이지와 자른 영역, 출력 해시를 기록한다. 총 보충 그림은 5개다.
- 신규 설명 수식 6개: 역변환, pinv/DLS, PD 평형 오차, 정책 전이, 행동 정규화, 할인율 시간 환산. 총 재조판 수식은 20개다.
- 추가 숫자 검사 8개는 `supplement_checks.py`와 실행 결과에 남겼다. 기존 고정 PD 실행 파일과 결과는 유지한다.
- 초기 탐색 후보 NMesGSXr8H4는 oEmbed에서 Pang-Yo Lab 영상으로 확인되어 Silver 공식 영상으로 인용하지 않았다. 실제 사용한 공식 녹화는 lfHX2hHRMVQ이며 en 자동 자막 2,880구간을 확보하고 일부 대응 구간을 읽었다.

최신 검토는 전체 음성 청취, 전체 Silver 강의 정독, Isaac Lab 실행, 공식 ETH 과제 훈련의 증거가 아니다. 본문에는 전체 자막을 복제하지 않고 한국어 개념 설명과 해당 시간 링크를 넣는다.
