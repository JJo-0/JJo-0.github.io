# 03장 원본·자막 대조 기록

2026-11-04. ETH Robot Learning 3강 Imitation Learning(2026-03-02)의 원본 링크, 이미지 사본, 시간 자막과 관련 1차 자료를 대조했다. 본문 설명은 해당 슬라이드 바로 아래에 배치했다.

- 공식 PDF는 다운로드했으나 암호화되어 무인증 본문 열람을 하지 못했다. 암호를 해제하거나 공식 PDF와 이미지 사본의 동일성을 검증하지 않았다. 공식 편집용 PPTX를 찾았다고 기록하지 않는다.
- 공개 사본의 특정 커밋 week-03 JPEG 45장을 다운로드했다. 운영·전환·감사·참고문헌 장 2·32·44·45를 생략해 41장을 본문에 표시한다. 45장 개요를 시각 확인했고, 12·14·17·20·22·25·26·28·40·41장은1600×900에서 추가 확인했다. 전 페이지의 작은 글씨까지 원해상도 정밀 검수한 것은 아니다.
- JPEG와 OCR 텍스트·단어 위치 TSV를 분리했고 중요 도표/수식 영역9개를 잘라 보관했다. 래스터 영역 분리이며 원본 벡터나 편집 가능한 수식 추출은 아니다. 추가 PDF 15개를 내려받았다. 처음6개는 페이지 이미지·본문 텍스트·텍스트 블록·포함 이미지 파일을 분리했고 나머지는 원본과 추출 텍스트를 보관했다.
- ETH 영어 자동 자막1편과 Berkeley CS285 공식 녹화 영어 자동 자막3편을 확보했다. 기존 NTU 자막1편도 재사용했다. ETH 기술 부분2:09–50:27과 보충 강의의 대응 구간을 읽었다. 전체 음성 청취로 기록하지 않는다. NTU는 authored or unspecified이며 수동 자막으로 단정하지 않는다. 공개 GitHub에는 자막 전문을 전재하지 않는다.
- 원본 비교를 통해 누적 오차 상한의 조건, DAgger의 정답 수집, 회귀 평균과 행동 모드, 자기회귀와 확산 단계, 계획 인식/제안의 정보 차이, 조건부 ELBO를 풀어 썼다. NVIDIA·Play-LMP 원 논문 도식2개와 직접 계산 그림2개를 본문에 추가했다. 관련 강의와 논문은 참고문헌뿐 아니라 해당 개념 설명에 연결했다.
- 독립 수식18개와 본문 수학98곳을 KaTeX로 재조판한다. 언어 순위 식은 정답 점수를 높이는 부호를 원 논문과 대조했다. ELBO는 일반적으로 등식이 아닌 하한이며, KL은 대칭 거리로 설명하지 않는다. 목표/계획, 행동/영상 재구성도 구별한다.
- 공식 HW3는 고정 커밋의 README와 코드만 참고했으며 실행하지 않았다. 직접 실행한 별도 스칼라 예제에서15개 수치 검사가 통과했다. 실제 로봇·MuJoCo·Diffusion Policy 실행 결과가 아니다.

파일별 URL·SHA256·자막 속성·분리 좌표·그림 출처·수치 결과는 [manifest.json](manifest.json), 페이지/시간/보충 개념 대응은 [review.json](review.json), 실행 방법은 [예제 README](../../labs/03-imitation-learning/README.md)를 따른다. 다운로드 원본·자막·분리 자료는 개인 Drive의03장 폴더에 보관한다.
