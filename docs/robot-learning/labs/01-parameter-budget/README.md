# FFN와 gated FFN의 파라미터 수

자체 작성한 가중치 개수 계산이며 공식 과제 정답이나 모델 훈련 결과가 아니다.

```bash
python3 parameter_budget.py
```

입출력 차원 64, 일반 FFN 중간 폭 192라면 가중치는 24,576개다. 같은 폭의 gated FFN은 36,864개이며 중간 폭을 128로 줄이면 24,576개다. 편향을 포함하면 각각 24,832개와 24,896개가 되어 일치하지 않는다. 정규화와 다른 모듈의 파라미터는 포함하지 않는다.

계산 근거: [GLU 논문 식 (2), (6) 및 2/3 폭 설명](https://arxiv.org/html/2002.05202v1#S2). 원 논문의 언어 모델 성능을 재현하지 않는다.
