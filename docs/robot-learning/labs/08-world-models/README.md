# 관측을 받아 다시 계획하기

저장소 루트에서 아래 명령을 실행하면 Python 3 표준 라이브러리만으로 [결과](result.txt)를 재현할 수 있다.

    python3 docs/robot-learning/labs/08-world-models/replan.py

위치 0에서 목표 1을 향한다. 모델의 이동 이득은 1이고, 가상 환경의 이득은 0.8이다. 한 번 계산한 계획을 끝까지 쓰는 경우와, 매번 측정한 위치에서 다음 명령을 새로 계산하는 경우를 비교한다. 센서 노이즈, 행동 제한, 물리 접촉을 생략한 1차원 예제다.
