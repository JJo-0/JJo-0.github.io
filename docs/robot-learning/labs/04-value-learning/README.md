# 04장 실행 예제

value_examples.py는 유한 확률 격자의 정확한 동적 계획법과 표본 기반 표형 Q-learning, 합성 잡음 편향, CEM, 액터 연쇄 미분을 확인하는 교육용 예제다. 공식 ETH 과제·Atari·DQN/DDPG·실물 로봇을 실행한 결과가 아니다.

Python3.13.15, NumPy2.5.4, Matplotlib3.10.7에서 다음을 실행했다.

~~~sh
python value_examples.py
~~~

저장소 내 파일 위치를 유지한다. results/summary.json, values.csv, cem.csv와 본문 자체 그림3개를 생성한다. 실행 시 쓰기 가능한 Matplotlib 캐시 디렉터리를 지정할 수 있다.

3×4 격자, 벽1개, 목표·위험 종료 칸 각1개를 사용한다. 의도한 방향80%, 양옆각10%이며 경계/벽에서는 제자리에 남는다. 목표 진입+1, 위험 진입−1, 그 외0, 종료 이후 가치0이다. 할인율0.9. 가치 반복과 정확한 선형 정책 평가/개선의 해를 비교한다.

Q-learning은 seed7로 비종료 상태와 행동을 균등하게 질의하고 환경에서 전이 표본24만 개를 뽑는다. 전이 행렬의 평균을 Q 목표로 주지 않는다. 학습률은 해당 상태–행동 방문 횟수의−0.65승이다. 모든 쌍이6502회 이상 방문됐다. 최대 Q 오차는 약0.026889, 학습한 탐욕적 정책의 가치와 정확한 최적 가치의 최대 차이는 이번 설정에서0이었다. 온라인 에피소드 탐색의 표본 효율이나 다른 환경의 성능을 증명하지 않는다.

추가로 두 참 행동 가치0에 표준편차0.5의 독립 잡음을 더해20만 번 비교한다. 같은 추정으로 선택/평가한 최대값 평균과 독립 추정으로 평가한 평균을 구별한다. 실제 Double DQN 네트워크는 독립이 아니므로 이 예를 그대로 성능 결과로 읽지 않는다.

CEM은 알려진 이차 함수의 최댓값0.65를 검색한다. seed17, 후보64개, 엘리트8개,5회, 표준편차 하한0.02다. 학습된 Q나 로봇 제어 결과가 아니다. 전이/종료, 벨만 고정점, 알고리즘 일치, 방문 범위, Q 오차와 정책 가치, TD·DoubleDQN, 편향, CEM·미분 등18개 검사가 통과했다. 스크립트 SHA256와 모든 설정·결과는 JSON에 남겼다.
