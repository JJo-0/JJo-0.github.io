# 03장 실행 예제

`imitation_examples.py`는 행동 복제와 데이터 집계, 다봉 행동 분포, 잠재 변수 ELBO를 확인하는 교육용 예제다. 실제 로봇 물리 시뮬레이터·ETH 공식 과제·신경망 정책 훈련 결과가 아니다.

## 재현

Python 3.13.15, NumPy 2.5.4, Matplotlib 3.10.7에서 실행했다.

```sh
python imitation_examples.py
```

스크립트 옆 `results/summary.json`, `results/rollouts.csv`와 본문의 자체 그림 두 개를 생성한다. 저장소 전체의 상대 경로를 사용하므로 파일 위치를 유지한다.

스칼라 상태에 선형 정책을 최소제곱으로 맞춘다. 처음 데이터 20개는 모두 (0,0)이므로 최소 노름 해의 기울기는 0이다. 일부러 범위가 좁은 데이터로 시작한다. 60단계 실행에서 방문한 상태마다 전문가 `clip(-0.8*x,-1,1)`의 정답을 받는 작업을 3회 반복한다. 초기 데이터는 보존하고 총 200쌍이 된다. 집계 뒤 선형 해는 약 -0.8이다. 일반 행동 복제 성능에 대한 비교 실험으로 해석하지 않는다.

학습 수집 seed는 7–9, 별도 평가 seed는 1000–1019다. 두 정책은 같은 평가 seed 20개로 각각 60단계 실행했다. 상태 RMS 평균은 이 설정에서 0.415916에서 0.035215로 줄었다. 상태 변화는 `x_next=x+clip(w*x,-1,1)+0.015+Normal(0,0.008)`이다. 전문가 라벨이 훈련 구간에서 포화되지 않는 것도 검사했다.

추가 검사는 ±1 행동의 MSE 평균, 고정 계수 혼합 밀도의 정규화, 자기회귀 조건부 확률의 정규화, 이산 2상태 ELBO와 실제 사후 분포의 KL 간극, 누적 오류 예의 상한을 포함한다. 의미 있는 수치 검사 15개가 통과했다. 버전·seed·스크립트 SHA256·모든 수치는 `results/summary.json`에 남겼다.

공식 HW3는 특정 커밋의 자료를 참고했으며 이 예제와 구별한다. 공식 과제나 Diffusion Policy를 실행했다고 기록하지 않는다.
