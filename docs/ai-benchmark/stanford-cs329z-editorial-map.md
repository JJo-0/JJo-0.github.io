# Stanford CS329Z를 활용한 AI 벤치마크 40편 집필표

2026년 11월 27일 기준. 강의는 평가를 설계하는 관점을 제공한다. 각 벤치마크의 문항 수, 점수, 리비전과 이용 조건은 해당 제작진의 논문·공식 구현에서 확인한다. 아래의 실험, 표, 그림은 블로그에서 새로 만들 예시다. 01–08은 이 브랜치에 한영 원고가 있고, 09–40은 집필 설계 단계다.

[연재 목차](./README.md) · [영상 11개 타임스탬프와 PDF 페이지](./stanford-cs329z-sources.md) · [Stanford 2026년 가을 공식 강의표](https://cs329z.stanford.edu/)

07편에서 문제에 맞는 선택지를 고른 모델과 파일을 올바르게 고친 에이전트를 비교한다. 23–25편에서는 이 차이를 함수 호출, 고객지원, 사용자 인터페이스에서 각각 시험한다. 40편에 이르면 독자는 직접 요청을 쓰고, 환경을 초기화하고, 종료 규칙과 채점기를 정해 결과를 재현할 수 있다.

아래 ‘강의’의 번호는 Stanford 서버의 **PDF 파일 번호**다. ‘영상’의 번호는 Stanford Online 재생목록 표기다. 페이지는 표지를 1로 세며, ‘제작진 원전’은 강의의 직접 적용 범위를 넘어서는 주제를 표시한다.
