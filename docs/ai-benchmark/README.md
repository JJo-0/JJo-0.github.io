## Publication contract

For each benchmark, preserve exact version, source, task count, prompt, tools, budget, grading rule, score unit and direction, limitations, and model/provider provenance. Distinguish provider-reported results from independent runs; use original or explicitly illustrative examples. Never publish empty placeholder articles. Check English parity, register translation hashes, and pass the existing CI before merging.
